## 迁移中真正得到的修改

前11年已经支持M01—M14：词义、关系、范围、证据、问法、例子与共享前提。它们为后六年大部分题提供可用解释，但“能解释”不等于“不熟练时能在限时内用出来”。M15—M16来自你的时间和改答自述，不冒充由文章统计得出。

后六年增补：

- **M17，共同判断逐人取交集**：2023年第35题。只知道说话者仍不足，还须处理Neither与共同命题。不允许从A未证明有益，推出A认定有害。
- **M18，作用、归因、充分性分离**：2022年第39—40题，2025年第32—35题等。观察变化、解释原因、适合所有地区分别需要证据。

## 未闭合的地方

2024年第21题中，较均衡与选项“平等受益”不是形式逻辑恒等。四选一允许在实际语境中择优；过度要求每词绝对等价也会错误排掉优项。此处需要保留语境，不另造绝对词禁选法。

2026年第30题参考选A。D的营销暴露也有局部支持，A依赖对知识准备与收束责任的综合解释。本轮保留此解释缺口，**不把120题全部记成无争议成功**。其余119题均已写出文本支持路径；这只描述当前复核记录，不是119/120的实测正确率。

本轮没有为每种理解状态测出相同得分，也没有可靠测出每个动作所需秒数。因此不能给出“某种模仿稳定70%”或“保证180分钟”的数字。

## 怎样让方案继续知道你

不用先做完17年，不另交长拆分报告。后续直接从2021开始，把你的第一次选择、自然译文或一句犹豫接到现有分支。首选和最终选择不同才记改答依据；单篇用时足以检查时间传播。错因与模拟不同就改模拟，未发生的错误不强迫练。

先回答“这里是哪种认识失效”，再判断只补词、重接关系还是加深论证。熟题改对只说明本次修复；新材料上再次能用，才加强迁移证据。整卷用时和得分决定策略是否真正有效，不要求在训练里人工把你逼到紧张。
