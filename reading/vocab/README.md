## 使用与校验说明

1. **优先刷风控三单元**：先过 **Unit 05（实测熟词僻义）**、**Unit 06（否定/让步/范围一票否决）** 与 **Unit 07（高频动词框架与关系短语）**，直接扫清最易读反方向、错接宾语的失分点；再刷 Unit 01–04（高频主干）与 Unit 08–10（三大主题底色）。
2. **每词盯住两件事**：看懂**考场义与搭配/期待位**，再把下面的**真题例证**顺一遍，确认放回句子里能直接反应方向和角色，不死背孤立中文。
3. **例证与统计口径**：各单元例证均取自 2016–2026 阅读 Part A 语料（包含文章正文、题干及 `[A]`–`[D]` 选项），复现年份按三类文本合并统计词形命中；熟词僻义单元（Unit 05）的实测年份反映词形出现年份，目标考义以例证与题眼说明为准。
4. **与仓库其他词库的分工**：日常词汇基本盘按 [`word/README.md`](../../word/README.md) 推进；单套真题逐段查词与 2020–2026 考前排雷配合 [`vocab/README.md`](../../vocab/README.md) 与 [`vocab/traps-and-frames.md`](../../vocab/traps-and-frames.md) 使用。
