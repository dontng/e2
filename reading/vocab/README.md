## 怎么使用这套风洞词库？

1. **绝不贪多**：每次只翻 1~2 个 Unit（像你翻 `word/` 一样），2 屏翻完，滑到底部直接点 `[Unit XX »]`；
2. **重点在风控**：先攻克 **Unit 05（变调熟词）**、**Unit 06（条件限定）** 与 **Unit 07（翻转短语）**，这三个单元直接决定你在真题中会不会一脚踏空；
3. **实弹试射**：当你把这 10 个 Unit 在脑海中建立起物理直觉后，挑出 2~3 篇近年真题实测，你会发现文章的逻辑阻力已被提前扫空了大半。
