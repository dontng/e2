# 阅读实验维护

本目录独立于新题型和作文工作规则。入口是README、diagnosis和当前年度原题；优先服从用户最新要求。

用户已于2026-10-05明确授权本轮及后续E2工作直接push到main，无需重复询问；完成质量和范围检查后执行推送。

- 不按30分、40分等标签模拟能力。基于用户已有首译与自述，改变可用词义、关系和证据，分离仍未解决的问题。
- discovery是潜在分支，diagnosis才登记个人证据。未知词、句子、题干、中心、论证、改答和时间传播都可成为问题，不限命题考点。
- 避免只制造低级错误。若基础关系已可靠，直接检查范围、证据身份、观点交集、择优边界、措施充分性等深层问题。
- 用户无需先做完17年，也无需交拆分表。收到自然选择、译文或困惑，回到原文就地修复；熟题改对与陌生题迁移分开。
- 原卷、OCR和解析可能交换选项或漏项。先核内容，再写字母；不得为参考答案制造原文没有的论证。
- 本轮68篇分支、14组对照、120题应用属于教师分析，不能报告用户实测正确率、压力表现或180分钟达成。2026第30题解释缺口继续保留。
- 年度页改变后同步discovery-data.json或validation-data.json；方法、来源与入口链接随之修订。题外已知缺口不因答对自动删除。
- 阅读为180分钟整卷总分服务。保留承重信息，允许不完整理解先答；不把训练长分析全部要求搬进考场。
