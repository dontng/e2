# 阅读理解：从不完整理解到可迁移得分

本目录独立管理英语二阅读 Part A。目标是为整卷 80 分训练提供阅读能力，不把总分当作词汇或句法等级；不要求学习者先做完 17 年，才有资格开始近六年。

制作顺序是：读取 2010—2026 的 68 篇、340 题 → 用不同理解状态暴露问题 → 整理解决方法 → 在 2021—2026 的 24 篇、120 题逐题审查应用。题干之外的核心概念、句法、观点与篇章问题同样进入发现范围。正确答案不能证明这些问题不存在。

## 先看什么

- [问题是怎样分层暴露的](experiment.md)：本轮实际使用的信息限制、补充顺序和证据边界。
- [已经有证据的个人问题](diagnosis.md)：把既往首译、本人自述与新模拟分开。
- [固定条件的14组差速演示](rounds.md)：只补一处，观察还剩哪一层困难。
- [得分与时间的约束](score-and-time.md)：处理纯猜、错误排除、改答与跨篇耗时。
- [解决方法](methods.md)：每种方法都有英文演示、操作和失效条件。
- [17 年问题发现](discovery/README.md)：每篇保留词汇不清、句法不清、局部理解、较完整理解与时间压缩下的不同分支。
- [2021—2026 应用结果](validation/README.md)：120 题的答案内容、证据、受限路径、较深干扰与方法缺口。
- [来源与版本](sources.md)：先核对文章和选项内容，再核对字母。

阅读教学保持展开。做题时移开教学页，不要求填写长量表、逐句精翻或先写拆分报告。收到真实选择、首译和用时后，直接用它们修订当前判断。

## 怎样理解本轮“验证”

本轮是教师对真实题目的方法应用审查，含受限信息的假设分支。它不是用户实测，不是模型真正失去已有知识后的盲测，也不是考场压力实验。方法覆盖、正确解释和模拟成功不能换算为用户得分或用时。

先记录前 11 年已有的方法能解释后六年哪些题，再登记后六年暴露的新边界，最后形成 17 年综合方法。时间切分只能限制规则的来源，无法抹去模型预训练知识；不称独立留出测验。

不要把“全部答案已解释”写成“这套方案已保证 80 分”。真实成果还须由学习者在低熟悉材料、180 分钟整卷内交付。首次、同题再做和新题迁移分别记录。
