# 阅读理解：考场动作与英文信号直觉

阅读 Part A 占 40 分，是整张试卷的绝对核心。在考场极短时间内，阅读的核心不是“把英文翻译成中文长句”，而是**建立直接从英文词块到逻辑事实的视觉反射**。

---

## 一、 考场打靶三动作

拿到真题 PDF，以 1 篇阅读（5 道题，15~18 分钟）为单位：

1. **路标与主干识别（踩油门与踩刹车）**：
   - 专有名词、人名、背景数据：**踩油门滑过**，不纠结细节。
   - 转折（`Yet`, `However`, `Instead`）、让步否定（`hardly`, `rarely`, `not all`）、作者态度动词（`dismiss`, `foster`, `overlook`）：**踩死刹车**，看清作者立场与动作方向。
2. **回文定位与同义对齐（English-to-English Alignment）**：
   - 用题干关键词回文锁定证据句。
   - 正确选项往往是原文事实**换了一套英文词**（例如原文 `unresolved` $\leftrightarrow$ 选项 `not been settled`）。不要经由中文翻译，直接核对英文语义等价。
3. **选项一票否决（The 1-Word Disqualification）**：
   - 看到选项中出现无文本支持的极端修饰或超标词（如 `all`, `guaranteed`, `nationwide`），立刻划叉排除。
