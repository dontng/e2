# 17年问题发现入口

本轮已逐篇整理2010—2026的68篇阅读。每篇保留五个不同理解状态、修复方向、题干之外的学习问题及时间压缩风险，共340条状态分支。**340条分支不是340道题的逐题错误实录**。前11年用于形成基础方法；后六年另有120道逐题应用记录。

这些是结合已有个人错误设计的教学假设：从模糊词义进入，但不会止于模仿低级错误。较完整理解后仍检查证据身份、责任层级、共同判断、时点与规则误用。各阶段不代表分数，也不代表每个人必然依次通过。

[固定条件、只补一处的实际演示](../rounds.md)展示怎样把一种错误和另一种错误分离；年度页给出更广的问题面。仅答对而错误前提仍存在，分支不结案。
