# 真题现场

[打开 2020 英语（二）完整试卷](20.html)。打开本地文件或使用 VS Code Live Server 均可；旧的 [`20-text1.html`](20-text1.html) 会进入完整试卷第 3—4 页。

## 一套卷子对应什么

```text
20.html                         2020 年入口，只装载资源
viewer/reader.css               双页、页边折叠、答题卡的共用样式
viewer/reader.js                翻页、键盘、计时、首次答案与复盘记录
tools/render-pages.py            从源 PDF 再生成无损纸页素材
papers/2020/pages.js            原卷页序和每组页面的现场提示
papers/2020/notes.js            Text 1 的 13 处原位解析与页内纵坐标
papers/2020/assets/page-*.webp  从原卷 PDF 无损渲染的 15 张纸页
../archive-e2/2020年考研英语二真题.pdf   原卷及完整打印来源
../e2-ocr/20.md                 可检索的全文 OCR
```

PDF 第一张是无页码封面，之后才是第 1—14 页。界面先单独显示封面，接着按第 1/2、3/4、……、13/14 页翻动，每一组都把奇数页放左边、偶数页放右边。原卷模式直接显示整张纸页的无损图像，包括字体、行距、页码和第 14 页图表。复盘时，只有带解析的页面才按段落边界拆成图像片段，把讲解插回原文行间；不需要解析的页面一直使用整页图像。

页面上方的“这一页怎么看”给出当前部分的考场动作和复盘重点。“Text 1 解析（13处）”可直接到第 3—4 页阅读原有复盘，旧入口 `20-text1.html` 也会自动打开解析与第一处“先读题”。打开解析只标记已看过解析，不会把本次作答记成交卷。开始计时后，可在“答题与复盘”记录 1—45 题选项、犹豫标记，以及 46—48 题纸面内容；首次答案、改动次数和用时会保留。交卷复盘后，针对有价值的题留下英文证据、当时的混淆和下次可执行的检查动作。看过解析后补选的题不冒充考场首次答案。记录保存在当前浏览器中，可导出本次与历次作答 JSON；开启新一轮会先归档旧记录。这里保存的是作答现场，不会因为看过解析就将问题判为已经掌握。

左、右方向键切换双页；在第 3—4 页复盘模式中，X 定位上一处解析、C 定位下一处解析，Enter 展开或折叠。多个解析可同时打开，滚轮始终滚动整页。Text 1 之外的原卷已全部到位；这些部分的逐题解析需要以实际作答证据继续补进 `notes.js` 或按部分另建笔记数据，不应预先凭猜测标注个人错因。

## 增加下一套卷子的做法

共用的 `viewer/` 只负责交互和排版；每一套卷子在 `papers/<year>/` 内维护纸页素材、页序/提示、题号所在双页与解析数据。解析数据给出印刷页码、插入的纵坐标（PDF point）、折叠标题与正文，页面渲染器据此拆分该页，其他年份无需复制大段 HTML/CSS/JavaScript。新页先逐张对照源 PDF 核实页序、完整内容和图表，再给已有作答证据的句子和题目加解析；新增解析时检查折叠前是否仍与原卷逐页对应。
