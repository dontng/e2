## A. 内功（G）— 底层别扭

### G01 · 语境违和迟钝
- **别扭：** 字典第一项看着通顺就拿来用，没感觉到句子在拒绝它——whirlwind 只想到台风，却是在讲「行业被一场风暴席卷」；sustain 只知道「忍受」，却是「维持着那个幻觉不让它倒」
- **讲通：** 把译出来的中文代回句子里：「台风席卷了新闻界」——这是在说气象还是行业冲击？那种「嗯？」的感觉就是信号，词进了句子会被语境弯，弯完了才是意思
- **考场一步：** 主动词/关键名词译完，代回去：这个场景里它合适吗？不合适就换
- **状态：** 未开始

### G02 · 考场术语失忆
- **别扭：** 备考时背过定语从句、方式状语；遇题时想到了，一紧张还是照语感猜；术语像工具，紧张时找不到
- **讲通：** 术语是别人给问题起的名字，你要的是身体直觉——这里画面是什么、气口在哪、方向感对不对。术语飞了不影响你用感受解决
- **考场一步：** 术语想不起来时，改问自己：这里哪儿别扭？先解决别扭
- **状态：** 未开始

### G03 · 主干方向不稳
- **别扭：** alleviate the damage（减轻损害）译成「给 X 带来损害」；sustain the illusion of control 译成「忍受……控制的现象」；整句的因果方向反了，主语在做什么、做给谁——搞反了全句完蛋
- **讲通：** 先感受「谁在推谁、动词往哪走」，而不是先译字。alleviate 是「把重担往上提」，方向是减轻，不是施加。方向感建立之前，宾语不要碰
- **考场一步：** 落笔前 3 秒：这个动词是「给出/减少」还是「造成/加重」？
- **状态：** 印证中

### G04 · 介词空间感弱
- **别扭：** with/for/from 跟着哪个动作走说不清楚；alleviate damage with an apology 里的 with 是跟着 alleviate 还是 damage？
- **讲通：** 介词跟着前面那个动作走：alleviate damage **with** an apology = 「用道歉」来减轻（with 挂在 alleviate 上，表手段）；in which 和 which 绑死，不能拆开
- **考场一步：** 碰到介词：它挂在哪个动词上，那个动词在做什么？
- **状态：** 印证中

### G05 · 形近闪电混淆
- **别扭：** misery / mercy 差一个字母整句意思天地反；distinctive 看成 distribute（day61：要分发的）；quantify / qualify 高压下扫过去就混了
- **讲通：** 形近词先找字母锚点——N 想 Number（量化、算数字）；L 想 Level/License（定性、给资质）；distinctive 里有 distinct（独特、鲜明），不是 distribute
- **考场一步：** 形近词：先数差几个字母，找锚，再读义；不要靠字形整体印象
- **状态：** 未开始

### G06 · 阅读拐弯 unaware
- **别扭：** qualify 只知道「取得资格」，作者写 I want to qualify my previous statement 时不知道他在软化/限定前一句；interference 译成「参与」（day63），把负面干预降成了中性
- **讲通：** 「定性」= 给一件事画边界加条件，qualify a statement = 缩小前面那句话的范围，是「限定」不是「资格」；负面词（interference / harmed / wrongdoing）不要往中性拉
- **考场一步：** 阅读见 qualify/limit/restrict：这是作者在限制自己的主张吗？情绪词：是正向/负向/中性？
- **状态：** 未开始

### G07 · 盲译无检
- **别扭：** 从第一个词一路盲译到最后，没有停下来验证这句在说什么；错了也不知道哪一步断的；出来的是一行词语拼接，不是一句话
- **讲通：** 翻译是过程，不是解码。至少一次停：主干译完，这句话在说什么，通不通？
- **考场一步：** 主干译完，代回去读一遍：这是人话吗？
- **状态：** 印证中

### G08 · 气口断裂
- **别扭：** 长句逐字盯，不知道在哪换气；介词+what 和介词+which 分不清停在哪一侧；烫嘴的地方越来越多，读到一半断线放弃
- **讲通：** 介词 + what → 停在介词后面（介词跟动作走，先收住动作再开新段）；介词 + which → 停在介词前面（in which 绑死，整块是挂钩）
- **考场一步：** 长句先画出唯一一处换气点 //，再从这里拆两段读
- **状态：** 未开始

### G09 · 画面未激活
- **别扭：** orchestrate / alleviate / sustain 认得字形，脑子里没画面，就这么硬往中文套或者干脆漏掉；字形和意思是断开的两件事
- **讲通：** orchestrate = 指挥家在调度全局；alleviate = 把背包重量往上提、减轻负担；sustain = 撑着不让倒。画面锁义，比查义项表快
- **考场一步：** 关键动词：能在脑子里演出动作吗？演不出来先建画面再译
- **状态：** 印证中

### G10 · 成分蒸发
- **别扭：** harmed everybody（day61）—— everybody 整个消失，只译了 swept 的「扫过」；conscious mind alone（day58）—— alone 修饰对象挂错或直接漏掉；有些成分眼睛扫过去了，没有进大脑
- **讲通：** 英二翻译是按成分采分的：漏译一个关键成分 = 直接 ✗；不是整句全对才得分，也不是整句全错才失分
- **考场一步：** 译完对一遍：主语、动词、宾语、状语——几块，全有吗？
- **状态：** 未开始

### G11 · 主被动极性读平
- **别扭：** interference 译成「参与」（day63）把负面干预变成了中性；bad news breaks 译成「播报」（day60）把「爆出/披露」的力度抹平了；rarely/barely 读成普通否定句
- **讲通：** 动词和名词带着方向与力度。break（爆出）、interference（干预/干涉）都有主动施力的感觉；把它们弱化成中性词，整句逻辑的轻重就消失了
- **考场一步：** 译完情绪词/动词：原来是正/负/强/弱，我译的有没有变味？
- **状态：** 未开始

### G12 · 词缀视而不见
- **别扭：** free-market liberalism 写成「自由市场的自由」，-ism 消失了（day62）；architecture 写成「建造」（day59），-ture 指向建筑学这门学科；economic rigour 直接保留英文（day63），rigour 生词就跳过不译
- **讲通：** 词缀是意思的方向牌——-ism = 某种思潮/主义（capitalism / socialism / feminism）；-ture/-ure 指向抽象学科名；-ity/-ness 指向程度/性质；见到不认识的词先拆词缀，比整词瞎猜更稳
- **考场一步：** 不确定的词：先剥词缀——是思潮(-ism)、学科(-ture)、程度(-ity)还是动作(-ize/-fy)？
- **状态：** 未开始

### G13 · 行业专用义盲区
- **别扭：** outside directors 译成「外面的导演」（day60）；took up posts at American architecture schools 译成「建造学校拿下很多支持」（day59）；a school of design 译成「学院派的设计」，同位语整个丢了
- **讲通：** director / post / board / firm 这些词在公司治理语境里有一套义项——董事 / 职位 / 董事会 / 公司。考研英二常出公司治理、教育政策、城市规划这类题目，先想场景义，再想普通义
- **考场一步：** 认识的词放进句子里合适吗？商业/教育/政策语境先想行业义
- **状态：** 未开始

## B. 招式（P）— 可练的具体直觉

### P01 · 方向检（谁扛着谁）
- **别扭：** alleviate the damage → 带来损害（day55）；sustain the illusion → 忍受控制（day58）；整句后果读反
- **讲通：** 先看右边挂着什么（宾语），动词是在「给出/加到」宾语，还是「减轻/移走」宾语——方向定了再填词
- **考场一步：** 动词译完：它是在「给出/造成」还是「减轻/移走」？宾语受益还是受损？
- **关联内功：** G03
- **状态：** 印证中

### P02 · with 跟着动作
- **别扭：** with 当「和/用」乱译，不知道它跟着谁
- **讲通：** with 跟前面那个动作走表手段：alleviate damage **with** apology = 用道歉来减轻（with 挂在 alleviate 上）
- **考场一步：** with 前面哪个动词在用它做手段？
- **关联内功：** G04
- **状态：** 印证中

### P03 · 气口 what / which
- **别扭：** 不知道在介词后面还是前面换气，长句整体不知道停哪
- **讲通：** 介词+what → 停在介词后（focus on // what…）；介词+which → 停在介词前（hotel // in which…）
- **考场一步：** 找句子里有没有「介词+what」或「介词+which」，那就是 //
- **关联内功：** G08
- **状态：** 未开始

### P04 · 画面三件套（词根→画面→搭配）
- **别扭：** lev 知道是「提」，alleviate 还是错；词根和具体词挂不上钩
- **讲通：** ① 补物理画面（把背包重量往上提 = 减轻）→ ② 找同根熟词（elevator 电梯）→ ③ 搭配反推（药 + 疼痛 = 只能是缓解，不可能是加重）；三件套交叉验证
- **考场一步：** 卡壳时：能建出画面吗？同根词认识哪个？搭配方向对吗？
- **关联内功：** G09
- **状态：** 印证中

### P05 · 形近锚（N / L）
- **别扭：** quantify / qualify、distinctive / distribute（day61）高压下看走眼
- **讲通：** N → Number（量化/算数字）；L → Level/License（定性/给资质）；distinctive 里有 distinct（独特），词根不是 distribute
- **考场一步：** 形近词：先分字母找锚点，不靠字形整体印象
- **关联内功：** G05
- **状态：** 未开始

### P06 · qualify 画界
- **别扭：** I want to qualify my previous statement 译错，只知道资格义
- **讲通：** 定性 = 给前面那句话画边界、加条件、缩范围；这是作者在软化/限制自己的主张，不是在说取资格
- **考场一步：** qualify 在阅读里：是「取资格」还是「限定前一句话」？
- **关联内功：** G06
- **状态：** 未开始

### P07 · help do 即时性（语法当感受）
- **别扭：** help do / help to do 两种都背过，紧张时全飞
- **讲通：** 省 to = 动作紧挨着发生，不需要「为了」那一步距离——感受动作之间有没有距离
- **考场一步：** 见裸体动词（help do）：动作是不是紧挨着、强因果？
- **关联内功：** G02
- **状态：** 未开始

### P08 · 三道直觉检（形态·右侧·剥壳）
- **别扭：** 紧张时词性猜错（-ate 当成名词用，整句逻辑乱）
- **讲通：** ① 词尾：-ate/-ize/-fy 大概率动词；② 右侧：有宾语吗？有就是及物动词；③ 剥掉修饰语，主干还剩什么？——三道过完，词性不会再猜错
- **考场一步：** 词性不确定时：词尾、右侧、剥壳，过三道
- **关联内功：** G03 G02
- **状态：** 印证中

### P09 · 成分清单（不漏块）
- **别扭：** everybody 整个蒸发（day61）；alone 挂错位（day58）；三块成分只译出两块，还不知道漏了
- **讲通：** 英二翻译按成分采分——漏一块关键成分 = ✗；译完要主动数：原句有几块，我几块都给了吗
- **考场一步：** 译完：主语—动词—宾语—状语，逐块对；缺一块补一块
- **关联内功：** G10
- **状态：** 未开始
