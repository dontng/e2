# 内化库

> 跨句、跨对话的「别扭」与对策。Gemini 里你不一定说得清问题，但感受存在——这里用**感受语言**收条目，不用中学语法术语堆章名。  
> **状态**由你改：`未开始` / `印证中` / `已内化`  
> 日 probe 会写「今天触发了哪几条」；印证够了请自行改状态。

## A. 内功（G）— 除单词外要定制的底层别扭

### G01 · 语境违和迟钝
- **别扭：** 字典第一项看着顺眼就采纳，Salute→敬礼这类语境打架察觉慢
- **讲通：** 违和感是信号；先信句子在说什么，再信词条
- **考场一步：** 译完名词扫一眼：在这场景里顺眼吗？
- **状态：** 未开始

### G02 · 考场术语失忆
- **别扭：** 背过「定语从句、方式状语」，一紧张标签全飞，还是凭模糊语感硬译
- **讲通：** 中学语法是别人的标签；你要的是身体直觉（气口、方向、画面）
- **考场一步：** 术语想不起来时，改问：哪里别扭？先解决别扭
- **状态：** 未开始

### G03 · 主干方向不稳
- **别扭：** 减轻↔带来、主谓关系整句读反；长句译到一半放弃
- **讲通：** 先感受「谁推着谁、往哪走」，再填词
- **考场一步：** 译前 3 秒：方向反了吗？后半句丢了吗？
- **状态：** 印证中

### G04 · 介词空间感弱
- **别扭：** with/for/from 跟着谁走说不清；alleviate with 类手段状语懵
- **讲通：** 介词跟着前面的动作；in which 和 which 绑死成钩
- **考场一步：** 见到介词：它是跟着哪个动词/名词的那一步？
- **状态：** 印证中

### G05 · 形近闪电混淆
- **别扭：** misery/mercy、quantify/qualify 高压下看错字母整句逻辑崩
- **讲通：** 形近词先找字母锚点（N/L…），再读义
- **考场一步：** 形近碰面：先分字母，再读句
- **状态：** 未开始

### G06 · 阅读拐弯 unaware
- **别扭：** 只知 qualify=资格，不知「给前面的话加边界」；态度题、转折处翻反
- **讲通：** 定性=画界；作者 soften 语气时常在 qualify
- **考场一步：** 阅读见 qualify/qualification：先想是「资格」还是「限定」
- **状态：** 未开始

### G07 · 盲译无检
- **别扭：** 开卷就从第一个词译到最后，不做检查点，错了也不知道哪一步断的
- **讲通：** 翻译是过程，不是解码串；要有 3 秒检
- **考场一步：** 落笔前先气口 //，再方向检，再写
- **状态：** 印证中

### G08 · 气口断裂
- **别扭：** 逐字盯，不会换气；长句读到烫嘴
- **讲通：** what 切在介词后，which 切在介词前；先顺下来再抠
- **考场一步：** 长句先找唯一 //，再理解
- **状态：** 未开始

### G09 · 画面未激活
- **别扭：** 认得词形，脑子里没有画面，orchestrate/alleviate 等译得生硬或漏
- **讲通：** 词是画面不是释义表；指挥家、往上提重量…
- **考场一步：** 关键动词/名词：脑子里有画面吗？没有就先建画面
- **状态：** 印证中

### G10 · 长句心理放弃
- **别扭：** 看到从句嵌套就想逃，译半句留半句
- **讲通：** 不必一次吃完；// 切成两口吃
- **考场一步：** 再长也先只拿 // 前这一段
- **状态：** 未开始

### G11 · 主被动极性读平
- **别扭：** rarely are provoked、被…困扰 等读成中性「去想/被打扰」；语气轻重、谁推谁搞平
- **讲通：** 动词带着方向与力度；被动 often = 外界在推你，不是「我自己想想」
- **考场一步：** 见到 be + 过去分词：谁在对谁施力？语气是轻还是重？
- **状态：** 未开始

## B. 招式（P）— 可练的具体直觉

### P01 · 方向检（谁扛着谁）
- **别扭：** 整句后果搞反（alleviate→带来）
- **讲通：** 右边挂着什么、动词往哪推
- **考场一步：** 主谓方向对吗？
- **关联内功：** G03
- **状态：** 印证中

### P02 · with 跟着动作
- **别扭：** with 当「和/用」乱译
- **讲通：** with 跟动词走，表手段；focus on // what…
- **考场一步：** 介词 with：前面哪个动作在用它？
- **关联内功：** G04
- **状态：** 印证中

### P03 · 气口 what / which
- **别扭：** 长句读到缺氧
- **讲通：** 介词+what → 停在介词后；介词+which → 停在介词前
- **考场一步：** 先画 // 再译
- **关联内功：** G08
- **状态：** 未开始

### P04 · 画面三件套（词根→画面→搭配）
- **别扭：** 懂 lev 却不会 alleviate
- **讲通：** 物理画面 + 同根熟词 + 搭配反推（药+痛=缓解）
- **考场一步：** 卡壳时补画面，不硬译中文
- **关联内功：** G09
- **状态：** 印证中

### P05 · 形近 N/L 锚
- **别扭：** quantify / qualify 等
- **讲通：** N→Number；L→Level/License
- **考场一步：** 形近先分字母
- **关联内功：** G05
- **状态：** 未开始

### P06 · qualify 画界
- **别扭：** I want to qualify my statement 译反
- **讲通：** 给前面的话加边界、软化
- **考场一步：** qualify 在阅读里先想「限定」
- **关联内功：** G06
- **状态：** 未开始

### P07 · help do 即时性（语法当感受）
- **别扭：** 死记 help do / help to do
- **讲通：** 省略 to = 动作紧挨着，省力、强因果
- **考场一步：** 见到动词裸形：是否「马上发生」
- **关联内功：** G02
- **状态：** 未开始

### P08 · 三道直觉检（形态·右侧·剥壳）
- **别扭：** 紧张时词性猜错（-ate 当名词）
- **讲通：** 词尾像动词吗？右边挂着谁？剥掉修饰还剩什么？
- **考场一步：** 不凭语感，过三道再定
- **关联内功：** G03 G02
- **状态：** 印证中
