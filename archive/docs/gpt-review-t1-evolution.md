# GPT 对 T1 世界设计的复盘与建议

> 2026-07-12
>
> 基于最新 T1 design docs、self-convergence analysis，以及 Claude + DeepSeek 对 T1 自收敛机制的讨论。

## 核心判断

T1 的方向是正确的：它不是普通英语批改工具，而是在尝试建立一个基于个人错误证据持续进化的训练系统。

但当前最大的风险是目标漂移：系统正在从「帮助考研英语提分」逐渐靠近「构建一个自演化 AI 学习系统」。后者具有研究价值，但必须始终接受前者约束。

最终评价标准不是系统是否复杂，而是：

```
今天发现错误
→ 生成精准训练
→ 明天减少同类错误
```

如果维护系统本身消耗超过训练收益，系统就会失败。

---

## 一、最重要的发现：Drill 必须训练反射，而不是展示知识

Day75 drill 的问题不是内容错误，而是训练目标错误。

一个 drill 如果包含多个认知操作：

- access to：to 后面是资源，不是动作
- from A to B：路径识别
- in which：关系回指
- objected to：动词搭配

那么它实际上不是一个专项训练。

正确方向：

```
一个错误指纹
    ↓
一个考场反射
    ↓
5 个同构句强化
```

目标不是让用户知道更多，而是让用户看到结构时自动触发正确判断。

---

## 二、当前 T1 的结构性风险：模型同时担任裁判和教练

当前闭环：

```
GPT 批改
 ↓
GPT 分类错误
 ↓
GPT 建立风险线
 ↓
GPT 生成 drill
 ↓
GPT 判断是否改善
```

问题：如果最初分类错误，后续所有优化都会围绕错误方向展开。

例如：

```
barriers to treatment
```

可能原因：

1. to 结构误判
2. barrier 固定搭配不足
3. 名词短语边界识别失败

系统不应该立即选择唯一解释，而应该保留多个假设，用未来样本淘汰。

---

## 三、建议增加：错误指纹竞技机制

当前模型：

```
错误 → 分类 → 训练
```

建议：

```
错误
 ↓
候选原因集合
 ↓
未来样本验证
 ↓
保留有效解释
```

例如：

```
FP-001
名词 + to + 名词 → 动作误判

证据：
access to
barriers to
solution to

状态：high
```

错误指纹比宏观风险线更适合训练。

---

## 四、Probe 的价值：记录认知流程，而不仅是语言错误

当前 T1 主要记录：

- 词汇错误
- 搭配错误
- 句法错误

但更深层的问题可能是：

- 是否先找主干
- 是否判断修饰范围
- 是否建立语义槽
- 是否直接进入逐词翻译

这些问题可能是多个表面错误的共同原因。

建议保留 Probe 层：

```
错误样本
 ↓
语言层解释
 ↓
认知流程假设
```

但不要过早训练，等待更多证据。

---

## 五、T1 下一阶段建议

不要继续扩大架构，优先验证闭环。

优先级：

### P0：错误指纹化

替代过粗的风险线。

目标：

```
每个高频错误都有唯一训练入口
```

### P1：窄专项 Drill

规则：

- 一个 drill 一个反射
- 5 个同构句
- 少解释，多触发

### P2：预警命中率记录

增加反馈：

```
今天预警是否击中了今天错误？
```

否则预警可能逐渐泛化。

### P3：风险线动态重构

允许：

- 拆分
- 合并
- 重命名

避免固定分类成为新的白名单。

---

## 最终判断

T1 最有价值的方向不是成为一个更聪明的批改器，而是成为一个持续识别个人错误模式、压缩训练路径的系统。

但是必须保持一个原则：

> 系统复杂度必须服从提分效果。

下一阶段不应证明 T1 能否无限自演化，而应证明：

一个错误指纹经过精准 drill 后，是否能稳定降低再次出现概率。
