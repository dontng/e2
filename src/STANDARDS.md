# 批改规范

四战英二，目标 39 → 65+。你每天翻译田静公众号的一句英文，AI 批改。批改不是给答案，是找出你读这句话时过程断在哪——主干没抓、方向读反、词义被幻觉锁死、还是长句跑到一半就放弃了。Vocab 和 Phrases 里的例句是你查字典的替代品，同时也是额外的阅读训练素材。

批改流水线入口：`scripts/day-pipeline-prompt.sh`。

---

## 翻译水平基准（固定）

你的首译均分稳定在 **3.5–4.5 / 10**，对应英二卷面约 35–45 分。

批改深度、例句难度、讲解细度始终按这个基准——不因某天发挥好就往上调，不因某天全错就往下降，不参照仓库历史文件。

常见卡点：多义词语境推断失败 / 介词方向反了（for/with/from）/ 主干找错 / 语义极性读反（减轻→带来、lack→没有）/ 长句后半段放弃。

---

## 文件结构

`new-day.sh` 生成骨架，顺序固定：

| 序 | Section | 谁写 |
|----|---------|------|
| 1 | `# Day N on YYYY-MM-DD` | 脚本 |
| 2 | `## 原句` | 你 |
| 3 | `## 我的理解和翻译` | 你 |
| 4 | `## 批改` | AI |
| 5 | `## 评分` | AI |
| 6 | `## Vocab` | AI |
| 7 | `## Phrases` | AI |
| 8 | `## 问答收录` | 留空，AI 不填 |
| 9 | `## 练习与习得` | 留空，AI 不填 |
| 10 | `## 复习区` | 脚本注入 + 你 + AI |

`## 原句` 和 `## 我的理解和翻译` 批改后不得改动。

---

## 批改

把你的译文放进代码块，在误处标 `[1]` `[2]`……再逐条说清楚：不只说"这里应该译成某某"——要说清楚**你读这句话时哪一步断了**：主干没找对、方向读反了、这个词的意象被字典义锁死了、结构复杂就半途放弃了。语气具体，不废话。

末尾：`**参考译文：**`（流畅书面中文）。

---

## 评分

从原句提取 **4–5 个**采分点（重要词汇、关键结构、特殊表达），按英二翻译阅卷习惯来。

| 标记 | 意思 | 得分 |
|------|------|------|
| ✓ | 完全命中 | 1 |
| △ | 方向对但有偏差 | 0.5 |
| ✗ | 未命中 | 0 |

总分 = 得分 ÷ 采分点数 × 10，步幅 0.5。△ 或 ✗ 后用逗号说清你写了什么、差在哪。

```markdown
## 评分

**6.5 / 10**

采分点（5点）：
- ✓ …
- △ … → 你写了什么，差在哪
- ✗ … → 你写了什么，差在哪
```

## Vocab

**收什么**：这次译文里译错、译漏、译偏的词，全收，不设上限，不凑数，不遗漏。

**怎么写**：每个词条恰好 **3 条例句**，不多不少。例句不从原句截取，但要围绕原句里那个词的用法有意构造：

| 例句 | 任务 |
|------|------|
| **扣原句** | 同骨架重演该词在原句里的位置与搭配；换场景或主语，结构不换 |
| **考纲迁移** | 英二常见场景里的活句，读起来像真实新闻/评论，不是教科书填空 |
| **防坑** | 专门对准这次的具体误译——极性反、形近、介词转向等，钉在批改的 [n] 或 ✗ 上打 |

造句字段已废除，三条例句完全承担其功能。

每条例句后必须附 `**例句意图：**` 一行，说清楚这句在干什么。

```markdown
### word *(词性)* · [🔊](https://www.merriam-webster.com/dictionary/word)

**词根**：（短语词条可省略）

**核心意象**：一两句中文锚定画面，不是罗列释义

- *例句* （简短中文提示）
  **例句意图：** 扣原句 — …
- *例句* （简短中文提示）
  **例句意图：** 考纲迁移 — …
- *例句* （简短中文提示）
  **例句意图：** 防坑 — 针对[n]/✗…
```

词性写法：*(n.)* *(v.)* *(adj.)* *(adv.)* *(prep.)* *(phrase)*。发音链接必须加，多词词条 URL 用连字符（`about-face`）。

## Phrases

**收什么**：这次译文里栽在结构/搭配块上的地方，全收。

**怎么写**：标准和 Vocab 完全一致——恰好 3 条，三句分工同上（扣原句、考纲迁移、防坑），不打折。

```markdown
### 结构名（中文提示）

**讲解**：逻辑说明 + 原句引用（> blockquote）

- *例句* （简短中文）
  **例句意图：** 扣原句 — …
- *例句* （简短中文）
  **例句意图：** 考纲迁移 — …
- *例句* （简短中文）
  **例句意图：** 防坑 — 针对[n]/✗…
```

## 复习区

`scripts/review.py inject` 自动注入（首译后第 3 天和第 7 天各一次），你盲译，首译分和参考译文藏在 HTML 注释里。

AI 只写「**复习批改：**」后的空白处，其余不动：
1. 过程对比（2–3 行）：哪里改了，哪里还卡着
2. 仍存的错误，最多列 5 条；质量好就肯定
3. 末行：`复习评分：X / 10`（首译 Y / 10，↑ / → / ↓）

评分口径和首译一致。
