# src 日课批改标尺

**立意：** 四战英二，目标 39 → 65+。每日一句田静翻译是训练引擎——练的是读句时的理解与翻译过程，不是攒词典。批改产出首先服务过程纠错与考场迁移，其次才是词汇拓展。

批改流水线入口：`scripts/day-pipeline-prompt.sh`。

---

## 学员档位（固定）

首译稳定在 **3.5–4.5 / 10**，对应英语二卷面约 35–45 分。

常见卡点：多义词语境推断失败、介词方向搞反（for/with/from）、主干找错、语义极性读反（减轻→带来、lack→没有）、长句后半段放弃。

批改深度和例句难度**始终按此档位固定**，不随某天得分浮动，不参照仓库历史文件调节。

---

## 文件结构

由 `new-day.sh` 生成骨架，顺序固定：

| 序 | Section | 谁写 |
|----|---------|------|
| 1 | `# Day N on YYYY-MM-DD` | 脚本 |
| 2 | `## 原句` | 学员 |
| 3 | `## 我的理解和翻译` | 学员 |
| 4 | `## 批改` | AI |
| 5 | `## 评分` | AI |
| 6 | `## Vocab` | AI |
| 7 | `## Phrases` | AI |
| 8 | `## 问答收录` | 留空，AI 不填 |
| 9 | `## 练习与习得` | 留空，AI 不填 |
| 10 | `## 复习区` | 脚本注入 + 学员 + AI |

`## 原句` 和 `## 我的理解和翻译` 批改后不可改动。`## 问答收录` 和 `## 练习与习得` AI 一律不填。

---

## 批改（`## 批改`）

核心任务：用学员的译文照镜子，找出读句过程断在哪一步。

把学员译文放进代码块，在误处标 `[1]` `[2]`……再逐条解释。每条解释必须说清**过程哪里断了**（主干找错、方向读反、词义幻觉、结构放弃……），不只给正确答案。语气耐心，具体。

末尾一行：`**参考译文：**`（流畅书面中文）。

---

## 评分（`## 评分`）

从原句提取 **4–5 个**采分点（重要词汇、关键结构、特殊表达），按英语二翻译阅卷习惯拆。

| 标记 | 含义 | 得分 |
|------|------|------|
| ✓ | 完全命中 | 1 |
| △ | 方向对但有偏差 | 0.5 |
| ✗ | 未命中 | 0 |

总分 = 得分 ÷ 采分点数 × 10，步幅 0.5。△ 或 ✗ 的说明用中文逗号衔接。

```markdown
## 评分

**6.5 / 10**

采分点（5点）：
- ✓ …
- △ … → 学员写了什么，差在哪
- ✗ … → 学员写了什么，差在哪
```

---

## Vocab（`## Vocab`）

收录本次**译文暴露的所有需讲解词**——译错、译漏、译偏的词全收，不凑数，不遗漏。词条数由当天误译决定，无上限。

每个词条**恰好 3 条例句**，不多不少。例句不从原句截取，但要围绕原句的词义与用法有意构造，三条分工固定：

| 例句 | 目的 |
|------|------|
| **扣原句** | 同骨架重演该词在原句里的位置与搭配；可换场景/主语，结构不换 |
| **考纲迁移** | 英语二常见场景里的活句，读起来像真正的新闻/评论，不是教科书填空 |
| **防坑** | 专门对准本次批改的具体误译——极性反、形近、介词转向等，钉在 [n]/✗ 上打 |

造句字段已废除，三条例句完全承担其功能。

每句后必须附一行 **`例句意图`**，说清这句在干什么：

```markdown
### word *(词性)* · [🔊](https://www.merriam-webster.com/dictionary/word)

**词根**：（短语词条可省略）

**核心意象**：一两句中文锚定画面，不是罗列释义

- *例句* （简短中文提示）
  **例句意图：** 扣原句 — …
- *例句* （简短中文提示）
  **例句意图：** 考纲迁移 — …
- *例句* （简短中文提示）
  **例句意图：** 防坑 — 针对[n]/✗…
```

词性写法：*(n.)* *(v.)* *(adj.)* *(adv.)* *(prep.)* *(phrase)*。发音链接必须加，多词词条 URL 用连字符（`about-face`）。

## Phrases（`## Phrases`）

收录本次**译文暴露**的关键句式/习惯用法块。标准与 Vocab 完全一致：恰好 3 条例句，三句分工同上（扣原句、考纲迁移、防坑），不打折。

```markdown
### 结构名（中文提示）

**讲解**：逻辑说明 + 原句引用（> blockquote）

- *例句* （简短中文）
  **例句意图：** 扣原句 — …
- *例句* （简短中文）
  **例句意图：** 考纲迁移 — …
- *例句* （简短中文）
  **例句意图：** 防坑 — 针对[n]/✗…
```

---

## 复习区（`## 复习区`）

由 `scripts/review.py inject` 自动注入（第 3 次前和第 7 次前各一次），学员盲译，首译分和参考译文藏在 HTML 注释里。

AI 复习批改只写「**复习批改：**」后的空白处，其余不动：
1. 过程对比（2–3 行）：哪里改善了，哪里还卡着
2. 仍存错误，最多列 5 条；质量好就肯定
3. 末行：`复习评分：X / 10`（首译 Y / 10，↑ / → / ↓）

评分口径与首译相同。
