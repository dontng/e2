# src/standard

Daily 当前执行规则以仓库根目录 [`STANDARD.md`](../STANDARD.md) 为准。`src/` 是精读与补弱线，服务于真题主干，不用每日文件数量代替真题进度。核心不是套用 0814 的版式，而是延续它的教学方法：从用户译文还原阅读过程，找到第一个失控点及其连锁反应，针对机制重新教读，再完成译对、译好和考研迁移。

最低执行要求：保留原句与用户首次译文；先以不编号的“这句话在说什么”讲清整体，数字小标题从后续讲解开始；正文统一以“你”指向用户，只有“我的翻译”区保留用户原始第一人称。讲解按今天这句话的信息块和真实断点组织，不参照历史文章，不习惯性地把每个单词拆成一节。例句只在能解决重点、难点、易错点或已错处时使用，数量不固定。可见正文最后结束在“从译对到译好”，不再追加考研总结或能力复盘。唯一判断是：在把这句话教懂、教会的前提下，删去没有继续帮助理解和应用的阅读开销。

## 评分

从这句话提取 4–6 个具体采分点：关键词义、关键结构、特殊表达、极性判断。按英二翻译阅卷标准取样，不凑数。

表格三列：采分点（用反引号标出关键词）/ 标记 / 说明（写了什么、差在哪）。

| 采分点 | 标记 | 说明 |
|--------|------|------|
| `key word` 词义/结构描述 | ✓/△/✗ | 写了什么，差在哪 |

✓ = 命中（1分），△ = 方向对有偏差（0.5分），✗ = 未命中（0分）。总分 = 得分 ÷ 点数 × 10，步幅 0.5。

## Vocab

收这次译错、译漏、理解有偏差的词。不收无关词，不凑数。

每个词条格式：

**`word`** *(词性)*

词根/词缀/词源，一两句带出含义。

- 例句一：vocabulary.com 风格，复杂真实，词义在句子里自明
- 例句二：李延隆风格，高级模仿原句骨架，换场景保留结构
- 例句三：易混词扎堆放一句，或针对这个词最容易踩的坑

一句话说清这个词：核心含义、用法要点、或这次错的根源在哪。
