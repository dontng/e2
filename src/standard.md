# src/standard

四战英二，39 → 65+。每天翻译田静一句，把读英语时的理解过程练扎实。

---

# 基准 (Baseline)

- 首译均分 3.5–4.5 / 10
- 常见断点：词义极性反、长句后半段放弃、介词方向错、主干找错
- 批改深度始终按这个区间，不随某天发挥波动，不参照仓库历史文件

---

# 批改 (Diff & Debug)

1. **注释原译 (Hide Input)**
   - 把 `## 我的翻译` 标题及翻译内容整块用 HTML 注释包裹：`<!-- ... -->`，不删内容；标题也在注释内

2. **得分置顶 (Score First)**
   - section 第一行：`> [!NOTE]` + `> **得分：N / 10**`

3. **标注错误 (Markup)**
   - 把译文复制进 code block，错误处直接插入 `[1][2]...` 标记

4. **逐条说明 (Explanation)**
   - 格式：`* **[n] \`word\` → "用户译法"**`
   - 说清断在哪一步，一句能说清不写两句
   - 词根词缀留给 Vocab，不展开；提到英文词一律加反引号；不出现语言学术语

5. **采分点隐藏 (Hidden Scoring)**
   - bullets 下方插入 HTML 注释块，内写采分点明细（3–4点，不凑数）
   - 格式：`✓/△/✗ \`key\`（中文描述） → 写了什么，差在哪`
   - ✓ = 1分，△ = 0.5分，✗ = 0分；明显扭曲原意该点最多 0.5 分

6. **参考译文 (Reference)**
   - 注释块下方给书面流畅中文译文

---

# 核心复盘 (Takeaways)

从本次批改内容里提炼，2–3 条。批改是原料，复盘是萃取——每条对应一个今天暴露的问题，但写法是"下次遇到这种情况该怎么读/判断"，不是"今天翻错了XXX"的陈述。

格式：`* **标签**：一句可操作的规则`

---

# Vocab

收这次译错、译漏、理解有偏差的词，不收无需解释的基础词，不凑数。

每个词条：

**`word`** 词性

**词根**：词根/词缀/词源，带出含义逻辑，同根词可顺带一提，去掉连接词废话

**核心意象**：一两句，建立对这个词的中心感知，结合本句语境点到位

- 例句一（vocabulary.com 风格，词义在句中自明，英二难度）
  *中文翻译*
- 例句二（同上，三条例句均为 vocabulary.com 风格）
  *中文翻译*
- 例句三（同上）
  *中文翻译*

**易混**：自然段落形式，不做成第四条例句。对比易混词的核心区别，给出判断标准。不用表格、不用编号、不用类句子形式——就是一段讲清楚这几个词怎么分。

末句点出核心含义或这次错的根源。

---

# Phrases

收认识单个词但整体读不懂的：固定搭配、习惯用法、小品词块。

格式同 Vocab，**词根**替换为**结构**（拆解短语各部分的语义方向），其余相同（含三条 vocabulary.com 风格例句 + **易混**自然段落）。
