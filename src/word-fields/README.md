# word-fields

整理**看起来应该相同、实际用起来不同**的单词。

## 立意

起初的想法是：按词根理解单词，同一个词根的词，释义应该是相通的。

实际不是。同根词在用法上分岔，引申义分岔得更远。concern / discern / certain 同出 cernere（分辨），但今天几乎没有可以互换的场合。

这个文件夹就是收这类词，把它们拆开。

## 两条轴

| 轴 | 例子 | 问题 |
|---|---|---|
| 同源不同义 | concern / discern / certain | 词根相同，用法各走各的 |
| 同义不同源 | decline / decrease / reduce | 中文压成一个词，英语内部有分工 |

## 想要什么样的答案

- 说清每个词**实际怎么用**，不是罗列释义
- 指出分岔点：从同一个词根出发，各自走到了哪里
- 判断依据要能直接用上——搭配、语境、能不能互换，不用语法术语
- 合法 ≠ 常用，标出哪个是实际常用的
