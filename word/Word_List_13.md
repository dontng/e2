# 考研英语二核心词汇手册 · Word List 13（全 72 词）

---

## 01 - 18

### 01. abolish
* **常用义**：v. 废除、废止（法律、制度、习俗）
* **底层骨架**：*ab-*（离开/消除）+ *ol*（生长） → 连根铲除使其彻底停止生长。
* **考研高频搭配**：abolish slavery/taxes（废除奴隶制/取消赋税）。

### 02. activate
* **常用义**：v. 激活、启动、加速起效
* **构词**：*act*（行动）+ *-iv* + *-ate* → 使进入动作状态。
* **考研高频搭配**：activate the immune system（激活免疫系统）。

### 03. agenda
* **常用义**：n. 议程、议事日程
* **底层骨架**：**“拉开的待办事项清单”**（词根 *ag-* 行动，字面为“必须要做的事”）
* **考场推导**：
  * 会议上按顺序讨论的条目 → **议程**
  * 政治或商业背后打着如意算盘的隐秘企图（a hidden agenda） → **意图、隐藏动机**
  * 排在政策讨论的最前列（at the top of the agenda） → **当务之急、首要议题**

### 04. alcohol
* **常用义**：n. 酒精、酒
* **考研高频搭配**：alcohol consumption（酒精摄入量/饮酒）。

### 05. alien
* **常用义**：n. 外星人；外侨；adj. 外国的；格格不入的
* **底层骨架**：**“彻底属于另一个世界、完全陌生异样”**（词源同 *alter* 另一个）
* **考场推导**：
  * 国籍属于他乡的人 → **外国人、外侨**
  * 某理念与自己的本性或价值观全然不容（ideas alien to our culture） → **格格不入的、背道而驰的**

### 06. ambitious
* **常用义**：adj. 有野心的、雄心勃勃的
* **考研引申**：修饰计划或工程宏大且极难实现（an ambitious plan/project） → **宏大的、耗资费力的**。

### 07. monarch
* **常用义**：n. 君主、帝王
* **构词**：*mon-*（单一/独占）+ *arch*（统治） → 天下唯有一人独掌大权者。
* **派生**：monarchy（n. 君主制）。

### 08. alarm
* **常用义**：n. 警报；警报器；v. 使恐慌
* **底层骨架**：源自意大利语 *all'arme*（拿起武器迎敌！）
* **考场推导**：社会舆论陷入焦虑惊恐（public alarm / alarming rate） → **惊慌、忧虑；令人担忧的**。

### 09. artistic
* **常用义**：adj. 艺术的、艺术家的；富有艺术才华的
* **考研高频搭配**：artistic creation/achievement（艺术创作/成就）。

### 10. astronomy
* **常用义**：n. 天文学
* **构词**：*astro-*（星星）+ *nomy*（运行法则） → 观察星辰运行法则的学科。

### 11. disaster
* **常用义**：n. 灾难、灾祸；彻底的失败
* **底层骨架**：*dis-*（恶劣/颠倒）+ *aster*（天星） → 星象逆乱降下大祸。
* **派生**：disastrous（adj. 灾难性的、极坏的）。

### 12. auction
* **常用义**：n./v. 拍卖
* **底层骨架**：词根 *auc/aug*（增加、抬高） → 竞价者逐轮向上加价。
* **考研高频短语**：put sth up for auction（将某物拿去拍卖）。

### 13. combat
* **常用义**：v. 与……搏斗、抗击；n. 战斗、格斗
* **考研高频搭配**：combat climate change / disease / crime（抗击气候变化/抵御疾病/打击犯罪）。

### 14. combination
* **常用义**：n. 结合、联合；结合体
* **考研高频搭配**：in combination with（与……相结合）。

### 15. embody
* **常用义**：v. 体现、具体象征；包含
* **底层骨架**：*em-*（使进入）+ *body*（肉身） → 把虚无飘渺的精神注入具象的血肉躯体里。
* **考场推导**：制度或法案充分展现了某种核心精神（the policy embodies the principle of equity） → **体现、代表、具象化**。

### 16. symbol
* **常用义**：n. 象征、符号、标志
* **考研高频搭配**：status symbol（身份地位的象征）。

### 17. bonus
* **常用义**：n. 奖金、红利；额外的好处
* **词源**：拉丁语 *bonus*（好的事物）。
* **考研微引申**：除核心收获外随附的意外惊喜（an added bonus） → **额外的好处**。

### 18. calculate
* **常用义**：v. 计算、核算；盘算
* **底层骨架**：古罗马用小石子（*calculus*）在沙盘上逐粒计数。
* **考研引申**：分词形容蓄意谋划而非偶然发生（a calculated risk / calculated move） → **深思熟虑的、蓄谋的**。

## 19 - 36

### 19. camp
* **常用义**：n. 营地；阵营；v. 宿营
* **底层骨架**：平原开阔地筑起的封闭驻地。
* **考场推导**：政治或思想流派分裂成对立阵垒（divided into two rival camps） → **阵营、派系**。

### 20. canal
* **常用义**：n. 运河；人工水渠
* **构词**：源自 cane（管子/芦苇） → 人工挖出的通水管渠。

### 21. captive
* **常用义**：n. 俘虏；adj. 被俘的、受制于人的
* **底层骨架**：词根 *capt-*（抓捕/囚禁） → 被关在铁笼里动弹不得。
* **考研商业大词**：**captive audience/market** → 没有其他竞品可挑、别无选择只能买账的受众 → **垄断受控市场、受限受众**。

### 22. conception
* **常用义**：n. 概念、见解；构想；受孕
* **底层骨架**：*con-*（全）+ *cept*（抓取） → 在子宫里接住受精卵，或在大脑里全盘捕捉到思路框架。
* **考场推导**：
  * 生命形成第一步 → **受孕**
  * 脑中形成的整体设想（one's conception of justice） → **观念、理解、构想**

### 23. conceive
* **常用义**：v. 想出、构想；怀胎
* **考场推导**：
  * 在脑海中构想出方案（conceive a plan/idea） → **构想、设想**
  * 否定短语难以置信（cannot conceive of a world without...） → **想象、设想**

### 24. recipient
* **常用义**：n. 接受者、领受人
* **构词**：*re-* + *cip/cept*（抓取）+ *-ent* → 把东西接在手里的人。
* **考研高频搭配**：award/welfare recipients（获奖者/福利救济领取人）。

### 25. occasion
* **常用义**：n. 场合、时机；重要庆典
* **底层骨架**：*ob-* + *cid/cas*（偶然落下） → 适逢其会降临的具体关口。
* **考场推导**：
  * 动词做及物用表示致使某事发生（occasion great anxiety） → **引起、致使**
  * 习惯短语（on occasion 偶尔 / on the occasion of 在……之际）。

### 26. cast
* **常用义**：v. 投、掷；n. 全体演员
* **底层骨架**：**“用力甩手把物体/视线/液体大步抛投出去”**
* **考场推导**：
  * 把视线或阴影投在某处（cast doubt on / cast a shadow over） → **投射、引起（怀疑/阴影）**
  * 选举中把选票投进票箱（cast a ballot / vote） → **投票**
  * 把滚烫铁水浇进模具冷却定型（cast iron） → **铸造**
  * 剧组挑选并撒向各个角色的演员班子 → **全体演职人员**

### 27. caution
* **常用义**：n. 谨慎、小心；v. 告诫、警告
* **考研高频短语**：with caution（审慎地）、throw caution to the wind（不顾一切冒失行事）。

### 28. conceal
* **常用义**：v. 隐藏、隐瞒
* **底层骨架**：*con-* + *ceal/cell*（地窖） → 关进地窖里遮掩不让人看。
* **反义词**：reveal（揭露）。

### 29. proceed
* **常用义**：v. 继续进行；前进（proceed with/to）
* **底层骨架**：*pro-*（向前）+ *ceed*（走步） → 迈开步子顺着往前走。
* **考研高频复数名词**：**proceeds** → 卖完货后回笼流进口袋的资金 → **收益、款项、收入**。

### 30. exceed
* **常用义**：v. 超过、超出；超越（界线/限度）
* **构词**：*ex-*（出）+ *ceed*（走） → 一脚跨出既定的白线之外。
* **考研高频搭配**：exceed expectations（超出预期）。

### 31. excess
* **常用义**：n. 过量、过度；adj. 额外的、过多的
* **考研高频搭配**：in excess of（超过、超出）、excess baggage（超重行李）。

### 32. predecessor
* **常用义**：n. 前任；前身（被替代的旧事物）
* **底层骨架**：*pre-*（前）+ *de-*（下）+ *cess*（走） → 走在前面并退下台去的人。
* **反义词**：successor（继任者）。

### 33. succession
* **常用义**：n. 一连串；接替、继承
* **底层骨架**：*sub-*（在后）+ *cess*（走步） → 一个紧跟一个在后面跟上。
* **考场推导**：
  * 一连串接踵而至（a succession of crises） → **一系列、接二连三**
  * 权柄有序交接（succession to the throne） → **继任、王位继承**

### 34. precede
* **常用义**：v. （在时间/空间上）先于……、在……之前发生
* **派生**：precedent（n. 先例）、unprecedented（adj. 史无前例的）。

### 35. cease
* **常用义**：v./n. 停止、中止
* **考研高频搭配**：cease to exist（不复存在）、ceasefire（停火协议）。

### 36. excel
* **常用义**：v. 擅长、在……中表现极其优异（excel at/in）
* **底层骨架**：*ex-*（超越）+ *cell*（升高） → 拔地而起、高人一头。
* **派生**：excellent（adj. 极佳的）、excellence（n. 卓越）。

## 37 - 54

### 37. census
* **常用义**：n. 人口普查、官方统计调查
* **底层骨架**：古罗马保民官手持册簿登记户口与征税财产。
* **考研社科搭配**：national census data（国家人口普查数据）。

### 38. charter
* **常用义**：n. 宪章；特许状；v. 包租（机/船）
* **底层骨架**：**“盖有帝王火漆封印的正式羊皮纸法律文书”**
* **考场推导**：
  * 联合国或大学办学大纲（the UN Charter） → **宪章、纲领**
  * 专属包租交通工具（charter a plane / flight） → **包租（特许租用）**
  * 美国基础教育改革高频（charter schools） → 享受公立拨款但自主立约管理的 → **特许学校**

### 39. chemistry
* **常用义**：n. 化学；化学成分
* **考研微引申**：两人之间产生的神奇默契火花（personal chemistry） → **相互吸引、默契契合**。

### 40. chronic
* **常用义**：adj. 慢性的；长期的
* **底层骨架**：词根 *chron-*（时间） → 像时间轴一样无休止拖拉纠缠。
* **考场推导**：
  * 医学疾病无法根治（chronic disease/pain） → **慢性的**
  * 经济社会恶疾常年积重难返（chronic shortage / unemployment） → **长期的、难以根除的**

### 41. clarity
* **常用义**：n. 清楚、清晰；清澈
* **派生**：clarify（v. 澄清、阐明）。

### 42. classification
* **常用义**：n. 分类、分级；归类
* **考研高频搭配**：classification system（分类体系）。

### 43. exclude
* **常用义**：v. 把……排除在外、不包括
* **底层骨架**：*ex-*（外）+ *clude*（关门） → 大门反锁，把你关在门外。
* **反义词**：include。

### 44. exclusive
* **常用义**：adj. 独有的、专有的；排他的；高档的
* **底层骨架**：把闲杂人等全关在门外，只供特定少数人独享。
* **考研高频搭配**：exclusive rights/access（独家专有权/独家获取权）、mutually exclusive（互斥的）。

### 45. disclose
* **常用义**：v. 揭发、透露、公开（秘密/信息）
* **底层骨架**：*dis-*（解开）+ *close*（关闭） → 把关着的盖子揭开让天下知晓。
* **考研高频搭配**：disclose financial information（披露财务信息）。

### 46. coalition
* **常用义**：n. （政党或国家的）联盟、同盟；联合政府
* **底层骨架**：*co-*（共同）+ *al*（生长滋养） → 多个原本分散的弱小实体抱团长在一起。
* **考研高频搭配**：form a coalition（组建联合政府/结成同盟）。

### 47. coast
* **常用义**：n. 海岸、海滨
* **底层骨架**：**“顺着滑溜溜的边缘无需用力地往下溜滑”**
* **考场推导**：
  * 陆地与海洋交接的边缘线 → **海岸**
  * 动词汽车挂空挡滑行，引申为人生毫不费力得过且过（coast through exams / life） → **顺畅滑行、得过且过毫不费力地渡过**

### 48. colony
* **常用义**：n. 殖民地；（动植物）群体
* **底层骨架**：词根 *col-*（耕作） → 派人去异国土地拓荒开垦建立的据点。
* **考研生物搭配**：a bee/ant colony（蜜蜂群/蚁群）。

### 49. consultant
* **常用义**：n. 顾问、咨询师；专科医生
* **考研高频搭配**：management consultant（管理咨询顾问）。

### 50. cosmic
* **常用义**：adj. 宇宙的；外层空间的
* **词源**：源自 cosmos（秩序井然的宇宙）。
* **考研引申**：规模极其宏大（of cosmic proportions 极其巨大的）。

### 51. discourage
* **常用义**：v. 使灰心、使沮丧；阻碍、劝阻
* **底层骨架**：*dis-*（剥离）+ *courage*（勇气） → 抽走对方胸膛里的胆量。
* **考研高频搭配**：discourage sb from doing sth（劝阻某人做某事）。

### 52. accordingly
* **常用义**：adv. 相应地；因此（逻辑衔接词）
* **底层骨架**：*accord*（顺应一致） → 顺应着前因做出的自然反应。
* **考场推导**：根据客观条件调整自身行为（we must adjust our plans accordingly） → **相应地、照着所说的办**。

### 53. recover
* **常用义**：v. 恢复；康复；追回
* **底层骨架**：**“重新拿回原本属于自己的东西”**（*re-* + *cover* 覆盖/获取）
* **考研高频短语**：recover from a crisis/illness（从危机/疾病中恢复过来）。

### 54. incredible
* **常用义**：adj. 难以置信的；极好的
* **构词**：*in-*（不）+ *cred*（相信）+ *-ible* → 离奇到让人不敢相信的。

## 55 - 72

### 55. concrete
* **常用义**：n. 混凝土；adj. 具体的
* **底层骨架**：*con-*（聚拢）+ *cret/grow*（凝结生长） → 各种砂石水浆凝结成硬邦邦的实在石头。
* **考场推导**：
  * 建房用的灰泥硬石 → **混凝土**
  * 相比空中楼阁的抽象理论，踩在硬邦邦土地上的实据（concrete evidence / proposal） → **确凿具体的、有形的**

### 56. agriculture
* **常用义**：n. 农业、农学
* **构词**：*agri-*（田地）+ *culture*（耕作/培育）。

### 57. occupy
* **常用义**：v. 占用（时间/空间）；占领；使忙于（occupy oneself with）
* **派生**：occupied（adj. 使用中的、忙碌的）、occupation（n. 职业/占领）。

### 58. accurate
* **常用义**：adj. 精确的、准确无误的
* **底层骨架**：*ad-* + *cure*（照料/关照） → 倾注心血反复校对、没有半点差池。

### 59. curious
* **常用义**：adj. 好奇的；求知欲强的；奇特古怪的
* **考研微引申**：某事显得反常惹人嘀咕（a curious fact） → **不同寻常的、古怪离奇的**。

### 60. curriculum
* **常用义**：n. （学校的）全部课程、教学大纲
* **底层骨架**：词根 *curr-*（跑/赛道） → 学生从入学到毕业必须全程跑完的知识赛道。
* **语法点**：复数形式为 **curricula**。

### 61. dense
* **常用义**：adj. 密集的、浓密的；愚钝的
* **考研微引申**：书籍或理论写得密不透风极难读通（dense text / prose） → **晦涩难懂的、内容密集的**。

### 62. density
* **常用义**：n. 密度、浓度
* **考研高频搭配**：population density（人口密度）。

### 63. contradict
* **常用义**：v. 与……相抵触、反驳；相矛盾
* **底层骨架**：*contra-*（反向）+ *dict*（说话） → 专门反着对方的话唱反调。
* **考研题干高频**：The finding contradicts the belief that...（这一调查结果推翻了普遍认为……的观点）。

### 64. dictate
* **常用义**：v. 口授；发号施令；支配、决定
* **底层骨架**：**“在上位居高临下大声念话，下属唯唯诺诺依言照办”**（词根 *dict* 说话）
* **考场推导**：
  * 老板口述信件让秘书记录 → **听写、口述**
  * 独裁者发号施令 → **强令、独裁统治**
  * 客观规律或常识对决策起到决定性控制（common sense dictates that...） → **支配、决定、硬性要求**

### 65. dose
* **常用义**：n. （药物的）一剂、一服；v. 给……服药
* **考研引申**：用于抽象事物的一定分量（a heavy dose of reality 一记残酷的现实大棒）。

### 66. mandate
* **常用义**：n. 授权；正式命令；v. 强制执行
* **底层骨架**：**“把盖着官印的权柄稳稳塞到受托人手里”**（*mand* 手 + *date* 交付）
* **考场推导**：
  * 选民投票托付给政府的执政合法授权（a popular mandate） → **选民授权、执政许可**
  * 官方红头文件硬性下令强制推行（laws mandate that...） → **强制要求、正式法令**

### 67. edition
* **常用义**：n. （出版物的）版本；版次
* **底层骨架**：*e-*（出）+ *dit/give*（给予） → 公开给印出来的读物。
* **考研高频搭配**：paperback edition（平装版）、digital edition（数字版）。

### 68. division
* **常用义**：n. 分开、分配；除法；分歧；部门
* **底层骨架**：拿刀横向切开划分。
* **考场推导**：
  * 大集团旗下的专门业务分支（the marketing division） → **部门、业务分部**
  * 社会群体间不可调和的鸿沟（deep social divisions） → **分歧、分裂**

### 69. document
* **常用义**：n. 文件、公文；v. 详细记录、用证据记载
* **底层骨架**：**“拿出真凭实据作为铁证来教导证明”**（词根 *doc-* 教授/证明）
* **考场推导**：
  * 白纸黑字的纸质文件 → **文件**
  * 动词用扎实史料或镜头持续跟踪存证（well-documented facts） → **翔实记录、记载、证明**

### 70. paradox
* **常用义**：n. 矛盾、悖论；看似矛盾却有道理的怪事
* **构词**：*para-*（超越/反常）+ *dox*（观点） → 超出大众常识逻辑框架之外的奇怪真理。

### 71. drastic
* **常用义**：adj. 猛烈的、急剧的；严厉彻底的
* **底层骨架**：词根 *dras/act*（行动） → 猛踩油门、不留回旋余地的大动作。
* **考研高频搭配**：take drastic measures（采取铁腕/断然措施）。

### 72. deduce
* **常用义**：v. 推论、推断、演绎
* **底层骨架**：*de-*（向下）+ *duce*（引导） → 从顶层公理大前提顺藤摸瓜一路往下导出具体结论。
* **辨析**：
  * **deduce**：演绎推理（从普遍真理往个别现象推）
  * **induce**：归纳推理（从一堆个别琐碎现象往普遍真理总结）
