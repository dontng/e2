# 考研英语二核心词汇手册 · Word List 18（全 31 词）

---

## 01 - 16

### 01. blueprint
* **常用义**：n. 蓝图；行动方案、规划
* **拆分**：*blue*（蓝色）+ *print*（晒印/打印） → 工程师在蓝底上晒印出来的工程建筑图纸。
* **考场推导**：
  * 建筑工程图纸 → **蓝图**
  * 施政或商业的一揽子详细行动方案（a blueprint for economic reform / action） → **行动规划、纲领蓝图**

### 02. censorship
* **常用义**：n. 审查制度、审查机构
* **底层骨架**：*censor*（审查官）+ *-ship*（制度/状态） → 官方派专人审查出版物、言论或影视。
* **考研高频搭配**：media/press censorship（媒体/新闻审查）。

### 03. copyright
* **常用义**：n. 版权、著作权；v. 获得……的版权
* **拆分**：*copy*（复制/抄写）+ *right*（法定权利） → 独家合法复制出版的排他性权利。
* **考研高频搭配**：copyright infringement/violation（侵犯版权/著作权）。

### 04. deadline
* **常用义**：n. 最后期限、截止时间
* **底层骨架**：*dead*（死亡）+ *line*（线） → 原指南北战争监狱四周划定的死线，越过一步即遭射杀。
* **考研高频搭配**：meet a deadline（赶上截止期限）、miss a deadline（错过最后期限）。

### 05. framework
* **常用义**：n. 框架、骨架；参照准则、体制结构
* **拆分**：*frame*（构架/外框）+ *work*（结构体） → 支撑整个大厦不倒的骨干承重架。
* **考场推导**：社科议论文指推行方案的制度大盘或分析框架（within the legal/regulatory framework） → **法律/监管框架、体制结构**。

### 06. greenhouse
* **常用义**：n. 温室、玻璃花房；adj. 引起温室效应的
* **拆分**：*green*（绿植）+ *house*（房屋）。
* **考研环境常客**：**greenhouse effect**（温室效应）、**greenhouse gas emissions**（温室气体排放）。

### 07. guideline
* **常用义**：n. （常用复数 guidelines）指导方针、行动准则、操作指引
* **拆分**：*guide*（指引）+ *line*（准绳/路线） → 前行时脚下画好的安全路线。
* **考研高频搭配**：issue new guidelines（发布新的指导方针）。

### 08. hardship
* **常用义**：n. 艰难、困苦、拮据的生活境况
* **拆分**：*hard*（艰难）+ *-ship*（状态境遇）。
* **考研高频搭配**：economic/financial hardship（经济拮据/财务困境）。

### 09. headline
* **常用义**：n. （报纸等的大字）标题；（复数 headlines）头条新闻
* **拆分**：*head*（版面最顶部）+ *line*（一行字）。
* **考研高频短语**：hit/make the headlines（登上头条新闻、引发轰动）。

### 10. lawsuit
* **常用义**：n. 诉讼、官司（民事起诉）
* **拆分**：*law*（法律）+ *suit*（跟随/程序） → 依法依规将对方告上法庭的程序。
* **考研高频搭配**：file/bring a lawsuit against...（对……提起诉讼）。

### 11. mankind
* **常用义**：n. 人类（总称）
* **语法点**：指代整个人类群体时，**前面通常不加冠词 the**，且代词通常用单数对待（for the good of mankind）。

### 12. membership
* **常用义**：n. 会员资格；全体会员
* **拆分**：*member*（成员）+ *-ship*（身份状态）。
* **考研高频搭配**：membership fee（会费）、union membership（工会成员规模）。

### 13. nowhere
* **常用义**：adv. 无处、到处都不；n. 无名之地
* **考研高频短语**：
  * **nowhere near**：远非、离……还差得远
  * **get nowhere**：毫无进展、徒劳无功
  * **out of nowhere**：不知从何而来、突然冒出来。

### 14. outdoor
* **常用义**：adj. 室外的、户外的
* **辨析**：outdoor 是形容词（outdoor activities 户外活动）；outdoors 是副词（go outdoors 去室外）。

### 15. outlet
* **常用义**：n. 出口、排放口；发泄途径；专卖店/奥特莱斯；电源插座
* **底层骨架**：*out*（向外）+ *let*（放行/通水） → 内部积压的能量或物资向外宣泄跑出的开口。
* **考场推导**：
  * 积压的怒火或精力找到宣泄通道（an outlet for one's anger/energy） → **宣泄途径、发泄渠道**
  * 工厂库存大批量打折甩卖的直营商场（retail/factory outlet） → **直销店、特卖商城**
  * 墙壁取电开口 → **电源插座**

### 16. outlook
* **常用义**：n. 前景、展望；人生观、世界观
* **底层骨架**：**“站立在窗前向外张望所见的视野”**（*out* + *look* 看）
* **考场推导**：
  * 眺望未来经济的发展走势（economic/market outlook） → **前景、未来预期**
  * 一个人审视外部世界的整体认知底色（outlook on life） → **人生观、看待事物的态度**

## 17 - 31

### 17. overcome
* **常用义**：v. 克服、解决（困难）；战胜；（感情等）压倒、使难受
* **底层骨架**：*over*（从上方跨过）+ *come*（走过） → 抬腿迈过拦路险阻。
* **考场推导**：
  * 跨越心理或环境障碍（overcome difficulties/obstacles） → **战胜、克服**
  * 强烈情绪将人彻底淹没（be overcome with grief/smoke） → **被……击垮、受……压倒、窒息**

### 18. overseas
* **常用义**：adv. 在海外、在外国；adj. 海外的、国外的
* **拆分**：*over*（跨过）+ *seas*（大洋）。
* **考研高频搭配**：overseas students/markets（海外留学生/外国市场）。

### 19. overturn
* **常用义**：v. 彻底推翻、撤销（判决/先例）；打翻、倾覆
* **底层骨架**：**“从底部向上用力，整车彻底掀翻朝天”**（*over* + *turn* 转）
* **考场推导**：
  * 车辆翻车 → **倾覆、翻倒**
  * 最高法院撤销下级法官裁决或推翻历史先例（overturn a previous verdict/decision） → **正式推翻、撤销、平反**

### 20. safeguard
* **常用义**：v. 保护、捍卫；n. 防范措施、保障条款
* **底层骨架**：*safe*（安全）+ *guard*（守卫） → 筑起安全护盾防止侵害。
* **考研高频搭配**：safeguard national security / rights（捍卫国家安全/保障合法权益）。

### 21. setback
* **常用义**：n. 挫折、阻碍、倒退
* **底层骨架**：*set*（放置）+ *back*（向后倒退） → 正在向前推进的势头被硬生生往后推退了好几步。
* **考研高频短语**：suffer a serious setback（遭受沉重打击/面临重大挫折）。

### 22. somehow
* **常用义**：adv. 以某种方式、不知怎么地；不知为什么
* **考研语气考点**：常用于作者表达结果发生但机理难以名状（Somehow, the policy worked / We must solve it somehow） → **设法、总算、不知怎么搞的**。

### 23. somewhere
* **常用义**：adv. 在某处、到某处；大约、大概
* **考研数字引申**：用于修饰大致区间数值（somewhere between $10 and $20） → **大约在……上下**。

### 24. straightforward
* **常用义**：adj. 坦诚率直的；直截了当的、简单易懂的
* **底层骨架**：*straight*（笔直）+ *forward*（向前） → 毫无拐弯抹角，笔直向前铺展。
* **考场推导**：
  * 流程或问题极易理解不复杂（a straightforward task/process） → **简明易懂的、直截了当的**
  * 人为人处世有一说一（a straightforward person） → **坦率正直的**

### 25. undergo
* **常用义**：v. 经历、经受（变化/手术/考验）
* **底层骨架**：**“从重型滚筒底下一路穿行挺过去”**（*under* 在底下 + *go* 走过）
* **考场推导**：事态主语通常被动承受巨变（undergo dramatic changes / surgery / trials） → **经受、经历、接受（重大变化/手术）**。

### 26. underground
* **常用义**：adj. 地下的；秘密的；n. 地铁；地下组织
* **考研社科引申**：逃避监管与税收的地下灰产（underground economy） → **地下经济、隐形经济**。

### 27. underlie
* **常用义**：v. 构成……的基础；作为……的深层根源
* **底层骨架**：*under*（在下方）+ *lie*（平躺/卧倒） → 平躺在地面最深处，充当上面整栋建筑的承重基石。
* **考场推导**：
  * 作为显性表象背后的深层动因（principles that underlie the system） → **成为……的基石/深层原因**
  * 过去分词形式常做形容词：**underlying**（underlying causes/assumptions） → **潜在的、深层的、根本性的**。

### 28. undertake
* **常用义**：v. 承担、着手进行（艰巨工作）；承诺、保证
* **底层骨架**：*under*（在下头）+ *take*（接过来） → 走到担子底下，用肩膀接过来扛走。
* **考场推导**：
  * 接手重大课题或工程（undertake a task / research / project） → **着手进行、承担**
  * 正式立字据担保照办（undertake to do sth） → **承诺、答应**

### 29. update
* **常用义**：v. 更新、使现代化；向……提供最新情况；n. 最新信息
* **底层骨架**：*up*（向上提）+ *date*（日期） → 把时钟指针往前提赶到今天的最新日期。
* **考研高频搭配**：update software/skills（升级软件/更新技能）、keep sb updated（使某人随时知悉最新动态）。

### 30. upset
* **常用义**：v. 使心烦意乱；搅乱、打乱；打翻；adj. 难过的
* **底层骨架**：*up*（上）+ *set*（倒扣） → 底朝天倒置，把原本平稳妥当的桌面彻底弄翻打碎。
* **考场推导**：
  * 内心平静被彻底打乱 → **使心烦意乱、苦恼的**
  * 突发变故把原定计划彻底搅黄（upset the balance / plans） → **搅乱、打破（平衡/既定计划）**
  * 竞技体育弱者掀翻强者爆大冷门 → **爆冷战胜**

### 31. withdraw
* **常用义**：v. 撤退、撤回；提款；退出；沉默不语
* **底层骨架**：*with-*（向后/相反）+ *draw*（拉拽/牵引） → 反手把伸出去的触角或兵力往后拽回自身阵地。
* **考场推导**：
  * 从银行账户把存款拉出来（withdraw money/cash） → **提取（现金）**
  * 撤军或撤回已发出的言论申请（withdraw troops / an application / support） → **撤退、收回、撤销**
  * 人缩回自己的壳里拒绝与外部社交（withdraw into oneself） → **孤僻、自我封闭**
