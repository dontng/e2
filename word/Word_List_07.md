# 考研英语二核心词汇手册 · Word List 7（全 78 词）

---

## 01 - 20

### 01. attach
* **常用义**：v. 系上、贴上、附加
* **底层骨架**：**“把两样东西死死粘接绑定在一起”**
* **考场推导**：
  * 邮件附带文件（attach a file） → **附上**
  * 心态上把极重分量绑定在某事上（attach importance / significance to...） → **认为……具有（重要性）、重视**
  * 情感或组织上的依附归属（be attached to...） → **依恋于、隶属于**

### 02. attack
* **常用义**：v./n. 攻击、进攻
* **底层骨架**：**“猛烈扑向目标施加重击”**
* **考场推导**：
  * 军事肢体冲突 → **攻击**
  * 议论文言论猛烈抨击（attack the government's policy） → **抨击、非难**
  * 疾病急性发作（a heart attack） → **（病痛）发作**

### 03. contact
* **常用义**：n./v. 接触；联系
* **底层骨架**：*con-*（共同）+ *tact*（触碰） → 彼此身体或信息触碰到一起。
* **考研高频搭配**：come into contact with（接触到）、lose contact with（与……失去联系）。

### 04. contain
* **常用义**：v. 包含、容纳
* **底层骨架**：**“把四处散逸的东西死死圈扣在箱体内部，不让外溢”**（*con-* + *tain* 握持住）
* **考场推导**：
  * 容器装有物品 → **包含、容纳**
  * 政治医学社科中控制住疫情、怒火或危机蔓延（contain the outbreak / inflation） → **遏制、控制、克制（蔓延）**

### 05. sustain
* **常用义**：v. 维持、支撑；承受
* **底层骨架**：**“从最底下双手托举，让其长久立住不垮”**（*sus-* 下方 + *tain* 握持）
* **考场推导**：
  * 托举生命或经济持续运转（sustain economic growth） → **维持、持续支撑**
  * 硬生生扛住重创或损失（sustain severe damage / losses） → **遭受、蒙受（创伤/损失）**
  * 派生词 **sustainable** → 资源撑得住长远发展的 → **可持续的**

### 06. content
* **常用义**：n. 内容、容量；adj. 满意的
* **底层骨架**：**“被完完整整装在容器里面的东西”**
* **考场推导**：
  * 书本或网页装载的文字 → **内容、目录**
  * 心里的渴望被填得满满当当、不再索求（be content with） → **心满意足的、甘心的**

### 07. obtain
* **常用义**：v. 获得、赢得
* **底层骨架**：**“伸手去抓并紧握在手心里”**（*ob-* 面对 + *tain* 握持）
* **考场推导**：
  * 经过努力拿到手 → **获得、得到**
  * 法律或习俗长期稳固立足（customs that still obtain in this region） → 依然存在且管用 → **通行、适用、仍然有效**（不及物用法）

### 08. retain
* **常用义**：v. 保持、保留；记住
* **底层骨架**：**“往回拉住，不让其流失溜走”**（*re-* 回 + *tain* 握持）
* **考场推导**：
  * 把人才、权利或记忆留住不放走（retain staff / information） → **留存、保留、记住**

### 09. technology
* **常用义**：n. 技术、工艺
* **构词**：*techn-*（技艺/工巧）+ *-ology*（学科）。

### 10. technical
* **常用义**：adj. 技术的、工艺的；专业的
* **考研高频搭配**：technical terms（专业术语）、technical difficulties（技术难题）。

### 11. technique
* **常用义**：n. 技能、技法；具体手段
* **辨析**：technology 指宏观的“工业/科技体系”；technique 指完成具体某项操作的“手法、操作技巧”。

### 12. detect
* **常用义**：v. 发现、查明、侦察
* **底层骨架**：*de-*（剥除）+ *tect*（屋顶/遮盖物） → 掀开盖在上面的瓦片看个究竟。
* **考研高频搭配**：detect subtle changes（察觉微妙变化）、lie detector（测谎仪）。

### 13. temperature
* **常用义**：n. 温度、气温；体温
* **考研高频搭配**：run a temperature（发烧）、global temperature rise（全球气温上升）。

### 14. temporary
* **常用义**：adj. 暂时的、临时的
* **词源**：源自 *tempor-*（时间） → 只管当前这一小段时间的。
* **反义词**：permanent（永久的）。

### 15. attempt
* **常用义**：n./v. 企图、尝试
* **考研高频短语**：in an attempt to do sth（为了试图做某事……）。

### 16. tendency
* **常用义**：n. 倾向、趋势
* **考研高频搭配**：a tendency to do sth（做某事的倾向）、natural tendency（天然倾向）。

### 17. extend
* **常用义**：v. 延伸、扩展；延长
* **底层骨架**：**“向外拉长伸展”**（*ex-* 出 + *tend* 伸拉）
* **考场推导**：
  * 空间拉长或时间延期 → **延长、拓展**
  * 伸出手向对方施予好意（extend an invitation / gratitude / a warm welcome） → **表示、给予、发出（邀请/感谢）**

### 18. extent
* **常用义**：n. 程度、范围；广度
* **考研高频短语**：to a certain extent（在一定程度上）、to the extent that...（达到……的程度）。

### 19. extension
* **常用义**：n. 延伸、扩大；电话分机
* **考研点拨**：大学提交论文或合同履约申请宽限时间（apply for an extension） → **延期、宽限期**。

### 20. intense
* **常用义**：adj. 强烈的、剧烈的；高度紧张的
* **底层骨架**：*in-*（向内）+ *tend/tens*（绷紧） → 神经或情绪向内死死绷得极紧。
* **考研高频搭配**：intense competition（激烈的竞争）。

## 21 - 40

### 21. determine
* **常用义**：v. 决定；下定决心
* **底层骨架**：**“在荒野上打下界桩，彻底定死边界”**（*de-* 加强 + *term* 边界/期限）
* **考场推导**：
  * 定下意志不可更改 → **决心、决定**
  * 实验或刑侦测定具体数值（determine the exact cause / value） → 划定精准定性 → **测定、确定、查明**

### 22. contest
* **常用义**：n. 比赛、竞赛；v. 争夺；对……提出质疑
* **底层骨架**：*con-*（共同）+ *test*（作证/证词） → 双方站在法官面前当堂对峙辩驳。
* **考场推导**：
  * 在赛场上争夺胜负 → **比赛、竞争**
  * 动词对选举结果或法庭裁决表示不服抗辩（contest the election / will） → **提出异议、质疑、抗辩**

### 23. theatre
* **常用义**：n. 剧场、戏院；戏剧界
* **美式拼写**：theater。
* **考研引申**：军事大戏上演的场地（theatre of war） → **战区、战场**。

### 24. theory
* **常用义**：n. 理论、学说；推测
* **考研高频短语**：in theory（理论上，常后接 but 转折实际情况）。

### 25. entitle
* **常用义**：v. 给予……权利/资格；给……定书名
* **底层骨架**：**“在头顶冠上合法的头衔称号”**（*en-* 使 + *title* 称号/所有权）
* **考场推导**：
  * 赋予某人合法享受某种福利的资格（be entitled to sth / to do sth） → **使享有权利、使具备资格**
  * 派生词 **entitlement** 在社科真题中常指“国家法定社会福利”或“优越感、特权心理”。

### 26. tolerate
* **常用义**：v. 容忍、忍受；容许
* **考研点拨**：及物动词，强调即使不认同也克制容纳（tolerate different opinions）。

### 27. tolerant
* **常用义**：adj. 宽容的、容忍的
* **考研高频搭配**：be tolerant of...（对……包容容忍）。

### 28. tolerance
* **常用义**：n. 宽容、容忍；耐受力
* **考研微引申**：医学上身体对药物或酒精产生免疫惰性（develop a tolerance to drugs） → **耐药性、耐受力**。

### 29. track
* **常用义**：n. 轨道；足迹；v. 追踪
* **底层骨架**：**“在泥地上踩出的一串脚印”**
* **考场推导**：
  * 顺着脚印一路搜寻追踪（track animals / progress） → **跟踪、监测记录**
  * 保持在既定轨道上不跑偏（keep track of / on track） → **跟上进展、走在正轨上**
  * 职场过往的全部战绩记录（track record） → **过往业绩、历史记录**

### 30. trace
* **常用义**：n. 痕迹、踪迹；v. 追溯
* **底层骨架**：**“用笔尖或视线一寸一寸勾画线条源头”**
* **考场推导**：
  * 沿着时间倒着往上摸根源（trace the origin back to...） → **追溯、探究根源**
  * 名词修饰微乎其微的残留物（trace elements / without a trace） → **微量、少许；痕迹**

### 31. trail
* **常用义**：n. 乡间小径；痕迹；v. 拖拽；落后
* **底层骨架**：**“长长的尾巴拖在后头擦过地面”**
* **考场推导**：
  * 穿过森林踩出的一道细长土路 → **山径、小道**
  * 商业比赛或民调中成绩拖在别人屁股后面（trail behind rivals） → **落后于、落于人后**

### 32. trait
* **常用义**：n. （人的性格/生物的）特征、特质
* **考研高频搭配**：personality traits（人格特质）、inherited traits（遗传特征）。

### 33. attractive
* **常用义**：adj. 吸引人的、有魅力的
* **考研高频搭配**：attractive offer/prices（诱人的提议/优惠的价格）。

### 34. contribute
* **常用义**：v. 贡献、捐款；促成（contribute to）
* **底层骨架**：*con-*（共同）+ *tribute*（进贡/上缴） → 大家把份子钱凑在一起上贡。
* **考场推导**：
  * 向上凑钱捐款 → **捐助、贡献**
  * 成为促使事件发生的份子因素之一（contribute to global warming） → **促成、是造成……的原因之一**

### 35. contribution
* **常用义**：n. 贡献；捐献物；投稿
* **考研高频搭配**：make a significant contribution to（对……做出重大贡献）。

### 36. attribute
* **常用义**：v. 把……归因于（attribute... to...）；n. 属性
* **底层骨架**：*ad-* + *tribute*（归属/进贡） → 判定这笔账该算在谁头上。
* **考场推导**：
  * 把成功归于努力 → **归因于**
  * 事物身上所天然归属的特质标签 → **特征、特质、属性**

### 37. triumph
* **常用义**：n. 巨大胜利、成功；v. 战胜（triumph over）
* **底层骨架**：古罗马凯旋仪式的狂欢高歌。

### 38. typical
* **常用义**：adj. 典型的、有代表性的
* **考研高频搭配**：it is typical of sb to do sth（做某事是某人一贯的作风）。

### 39. union
* **常用义**：n. 工会；结合、联盟
* **底层骨架**：词根 *uni-*（单一） → 散沙抱团拧成一股绳。
* **考研高频搭配**：trade union（工会）、European Union (EU)（欧盟）。

### 40. unique
* **常用义**：adj. 独一无二的、独特的（unique to）
* **反义词**：common, ordinary。

## 41 - 60

### 41. urban
* **常用义**：adj. 城市的、城镇的
* **反义词**：rural（乡村的）。
* **考研高频搭配**：urban planning（城市规划）、urbanization（城市化）。

### 42. urgent
* **常用义**：adj. 紧急的、紧迫的
* **构词**：源自 urge（催促） → 事情在屁股后头火烧眉毛催着办。

### 43. urge
* **常用义**：v. 敦促、极力主张；n. 强烈的冲动
* **底层骨架**：**“在背后猛推一把，催着赶紧迈步”**
* **考场推导**：
  * 政府极力督促公众落实政策（urge sb to do sth） → **敦促、力劝**
  * 心底深处按捺不住的生理欲求（an uncontrollable urge to buy） → **强烈的欲望、冲动**

### 44. unusual
* **常用义**：adj. 不同寻常的、罕见的
* **反义词**：usual（通常的）。

### 45. valuable
* **常用义**：adj. 很有价值的、宝贵的；n. （复数 valuables）贵重物品
* **辨析**：invaluable 并不是“没有价值”，而是“价值大到无法估量、极其珍贵”（等同于 priceless）。

### 46. valid
* **常用义**：adj. 正当合理的；在有效期内的
* **底层骨架**：词根 *val-*（强壮/有价值） → 根基结实、站得住脚的。
* **考场推导**：
  * 论据逻辑无懈可击（a valid argument） → **符合逻辑的、站得住脚的**
  * 护照或合同在法律效力期内 → **有效的、具有法律效力的**

### 47. available
* **常用义**：adj. 可获得的、可利用的；有空的
* **考研阅读极高频**：resources available（可支配资源）、the best evidence available（现存最确凿的证据）。

### 48. variety
* **常用义**：n. 多样性、品种
* **考研高频短语**：a variety of（各种各样的）。

### 49. various
* **常用义**：adj. 各种各样的、千差万别的
* **考研同义替换**：diverse。

### 50. reveal
* **常用义**：v. 揭露、揭示；展现
* **底层骨架**：*re-*（反向）+ *veil*（面纱） → 把蒙在脸上的面纱猛然扯开。
* **考研题干高频**：The study reveals that...（这项研究揭示了……）。

### 51. revenue
* **常用义**：n. 财政收入、税收；公司营收
* **底层骨架**：*re-*（回）+ *ven*（来） → 资金在外流转一圈后流回到国库或账上。
* **考研高频搭配**：tax revenue（税收收入）、generate revenue（创造营收）。

### 52. convention
* **常用义**：n. 大型正式会议；社会传统惯例
* **底层骨架**：*con-*（共同）+ *vent*（来） → 所有人聚到一起来开会/立规矩。
* **考场推导**：
  * 某政党或行业全国大会 → **大会**
  * 大家约定俗成、心照不宣的做法（social convention） → **常规、传统习俗**

### 53. convenient
* **常用义**：adj. 便利的、方便的
* **考研语法点**：物作主语（It is convenient for sb to do sth），绝不能直接用人当主语说 "I am convenient"。

### 54. verbal
* **常用义**：adj. 口头的、言语的
* **底层骨架**：词根 *verb-*（字词/语言）。
* **考研高频搭配**：verbal agreement（口头协议）、verbal communication（口头沟通）。

### 55. universe
* **常用义**：n. 宇宙、天地万物
* **构词**：*uni-*（一）+ *verse*（转） → 围绕一个轴心旋转运转的万物整体。

### 56. universal
* **常用义**：adj. 普遍的、全体通用的；全宇宙的
* **考研高频搭配**：universal truth（普遍真理）、universal healthcare（全民医保）。

### 57. version
* **常用义**：n. 版本；（某人的）说法、叙述
* **底层骨架**：词根 *vert/vers*（转动/转换） → 换了一个视角转出来的切面。
* **考场推导**：
  * 软件更新的版本 → **版本**
  * 面对事故时当事人自己的口径（his version of the story） → **说法、主观叙述**

### 58. controversy
* **常用义**：n. 争议、争论
* **底层骨架**：*contro-*（反向）+ *vers*（转动） → 两边对着转、互不相让打嘴仗。

### 59. controversial
* **常用义**：adj. 有争议的、引起争论的
* **考研高频搭配**：a controversial issue/topic（具有争议性的话题）。

### 60. reverse
* **常用义**：v. 颠倒、彻底倒转；n. 相反面
* **底层骨架**：**“掉转车头，顺着原路挂倒挡往后退”**（*re-* 回 + *vers* 转）
* **考场推导**：
  * 撤销并逆转先前的判决或政策（reverse a decision/policy） → **彻底扭转、推翻、撤销**
  * 挂倒挡倒车（reverse the car） → **倒车**
  * 名词背部或反面（the reverse is true / in reverse） → **反面、相反情况**

## 61 - 78

### 61. invest
* **常用义**：v. 投资、投入（invest in）
* **底层骨架**：**“把代表权柄和庄重的法袍套在某人身上”**（词根 *vest* 衣服/背心）
* **考场推导**：
  * 把资金当作战袍投进市场获利 → **投资**
  * 正式授予官方权力和法度（be invested with power / authority） → **赋予、授予（权力）**

### 62. investment
* **常用义**：n. 投资、投资额；投入精力
* **考研高频搭配**：return on investment (ROI)（投资回报率）。

### 63. obvious
* **常用义**：adj. 显而易见的、明显的
* **构词**：*ob-*（在……对面）+ *via*（路） → 堂堂正正横在马路正当中，一眼就能看到。

### 64. victim
* **常用义**：n. 受害者、罹难者
* **考研高频短语**：fall victim to...（成为……的受害者/牺牲品）。

### 65. evidence
* **常用义**：n. 证据、证明；迹象
* **语法点**：不可数名词，不能加复数 -s（绝不能写 an evidence 或 evidences）。

### 66. provision
* **常用义**：n. 提供、供给；（复数 provisions）食品物资储备
* **底层骨架**：**“提前看准未来的需求并做好准备”**（*pro-* 前 + *vis* 看）
* **考场推导**：
  * 储备物资供养前方 → **提供、供应；干粮给养**
  * 法律合同提前预设并白纸黑字写死的条款（the provisions of the contract） → **法律条款、规定**

### 67. visual
* **常用义**：adj. 视觉的、视力的；n. 视觉图像
* **考研高频搭配**：visual arts（视觉艺术）、visual impact（视觉冲击力）。

### 68. convince
* **常用义**：v. 使确信、使信服；说服（convince sb of sth / to do sth）
* **底层骨架**：*con-*（全）+ *vinc*（征服） → 在思想上彻底把对方驳得心服口服。

### 69. virtue
* **常用义**：n. 美德、高尚品德
* **底层骨架**：**“男子汉大丈夫身上天然拥有的力量与优良品质”**（源自 *vir* 男人）
* **考场推导**：
  * 道德品性高尚 → **美德**
  * 考研最核心固定短语（by virtue of...） → 凭借其本身具备的硬实力 → **凭借、由于、依靠**

### 70. survival
* **常用义**：n. 幸存、存活；生存之道
* **考研高频搭配**：survival skills（生存技能）、the struggle for survival（生存斗争）。

### 71. vital
* **常用义**：adj. 至关重要的、生死攸关的；充满生机的
* **底层骨架**：词根 *vit-*（生命） → 关乎有没有命活下去的。
* **考场高频搭配**：play a vital role in...（在……中起生死攸关的作用）。

### 72. advocate
* **常用义**：v. 主张、提倡；n. 拥护者、倡导者
* **底层骨架**：**“站出来把嗓门扯得最大，为特定群体代言呐喊”**（*ad-* 向 + *voc* 呼喊）
* **考场推导**：
  * 为弱势群体或政策站台辩护 → **提倡、拥护**
  * 在法庭上专门替被告大声辩护的专业人士（尤指苏格兰/南非法律体系） → **辩护律师**

### 73. voluntary
* **常用义**：adj. 自愿的、志愿的
* **反义词**：compulsory（强制的、必修的）。

### 74. involve
* **常用义**：v. 涉及、牵扯；包含；使参与（involve sb in sth）
* **底层骨架**：*in-*（内）+ *volv*（卷进） → 卷入旋涡包在里头。

### 75. volume
* **常用义**：n. 音量；体积、容量；卷、册
* **底层骨架**：**“古老时代卷成厚厚一卷的羊皮纸卷轴”**（词根 *volv/volu* 卷）
* **考场推导**：
  * 一卷一卷的书本 → **卷、册**
  * 卷轴展开后霸占占据的三维空间大小 → **体积、容积**
  * 商业大盘货物流通的磅礴规模（sales/trading volume） → **交易量、总额**

### 76. revolution
* **常用义**：n. 革命；彻底变革
* **底层骨架**：*re-*（翻转）+ *volut*（转动） → 乾坤彻底翻转颠覆过来。
* **考研高频搭配**：Industrial Revolution（工业革命）、information revolution（信息革命）。

### 77. vulnerable
* **常用义**：adj. 脆弱的、易受伤害的（vulnerable to）
* **底层骨架**：词根 *vulner-*（伤口） → 身上露着软肉伤口、没有护甲保护。
* **考研高频搭配**：vulnerable groups（弱势群体）、vulnerable to market shocks（极易受市场冲击影响）。

### 78. aware
* **常用义**：adj. 意识到的、察觉到的（aware of）
* **考研高频搭配**：environmental awareness（环保意识）、raise public awareness（提高公众意识）。
