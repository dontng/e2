# 考研英语二核心词汇手册 · Word List 19（全 70 词）

---

## 01 - 18

### 01. academy
* **常用义**：n. 专科学院；研究院、学会
* **派生**：academic（adj. 学术的；n. 学者）。
* **考研高频搭配**：the Chinese Academy of Sciences（中国科学院）。

### 02. acceptance
* **常用义**：n. 接受、接纳；普遍认可、赞同
* **考研高频搭配**：gain widespread acceptance（获得广泛认可）。

### 03. acre
* **常用义**：n. 英亩（面积单位，1英亩 ≈ 4047平方米 / 6亩）
* **考研点拨**：多用于农业经济与土地资源类阅读（acres of farmland）。

### 04. afterwards
* **常用义**：adv. 后来、之后
* **美式拼写**：afterward；等同于 later on。

### 05. algorithm
* **常用义**：n. 算法、计算程序
* **底层骨架**：完成某项计算或数据决策所遵循的固化严密规则链条。
* **考研高频搭配**：AI/recommendation algorithm（人工智能/推荐算法）。

### 06. alive
* **常用义**：adj. 活着的；充满生机的
* **底层骨架**：**“有呼吸、保持高度清醒与活性”**
* **考场推导**：
  * 肉身存活
  * 考研固定短语修饰警惕心（alive to risks / danger） → 神经敏锐活跃 → **充分意识到、敏锐察觉到**

### 07. allowance
* **常用义**：n. 津贴、补贴；零花钱
* **底层骨架**：**“官方或父母允许并特批给你的定额富余量”**（源自 allow 允许）
* **考场推导**：
  * 定期发放的补贴（housing allowance） → **津贴、补助**
  * 免税额度（personal tax allowance） → **免税额**
  * 考研绝杀短语：**make allowance(s) for...** → 留出富余容错空间 → **考虑到、体谅、为……留出余地**

### 08. alphabet
* **常用义**：n. 字母表；初级入门常识
* **构词**：希腊字母前两个 alpha (α) + beta (β)。

### 09. altogether
* **常用义**：adv. 总共、完全地；总而言之
* **考研同义替换**：completely, entirely, in total。

### 10. array
* **常用义**：n. 阵列；一系列、大批；v. 排列、部署
* **底层骨架**：**“在战场上整齐列队排开的森严军阵”**
* **考场推导**：
  * 计算机或仪器排列 → **阵列、数组**
  * 考研高频量词短语（a vast array of products / choices） → 眼前齐刷刷铺开一整排 → **大量的、令人眼花缭乱的一系列**

### 11. automobile
* **常用义**：n. 汽车（美式常用，常缩写为 auto）
* **构词**：*auto-*（自动）+ *mobile*（移动） → 能自动移动的交通工具。

### 12. awkward
* **常用义**：adj. 令人尴尬的；笨拙的；棘手难处理的
* **底层骨架**：方向朝向逆反别扭，怎么摆都不顺手。
* **考场推导**：
  * 社交难为情（an awkward silence） → **尴尬的**
  * 处境或难题令人头疼（an awkward situation/question） → **棘手的、难堪的**

### 13. bachelor
* **常用义**：n. 单身汉；学士（学位获得者）
* **底层骨架**：初出茅庐、尚未成家立业或刚迈过学术初级门槛的人。
* **考研高频搭配**：bachelor's degree（学士学位）。

### 14. backward
* **常用义**：adj. 向后的；落后的；adv. 向后地
* **反义词**：forward（向前的）。
* **考研高频短语**：bend over backward to do sth（竭尽全力做某事）。

### 15. bargain
* **常用义**：n. 便宜货；买卖协议；v. 讨价还价
* **底层骨架**：**“在集市上互换筹码、反复拉扯确认的买卖”**
* **考场推导**：
  * 物超所值的实惠商品 → **便宜货**
  * 双方拍板妥协达成的交易 → **买卖协议、交易**
  * 谈判中手握的压舱筹码（bargaining chip / power） → **谈判筹码、议价能力**
  * 动词做及物短语出乎意料（bargain for/on sth） → 预料并算计到 → **料想到（常用否定形式）**

### 16. battery
* **常用义**：n. 电池；炮组
* **底层骨架**：**“成排并列放置、一同对外开火的重炮阵地”**（词根 *bat-* 击打）
* **考场推导**：
  * 串联在一起蓄电的电芯组 → **电池**
  * 考研抽象量词引申（a battery of tests / questions / interviews） → 像一排大炮连续轰炸一样连续砸过来的 → **一整套、一大串（测试/提问）**

### 17. beam
* **常用义**：n. 光束；横梁；v. 笑容满面；播送
* **底层骨架**：**“笔直延伸的一道坚实大木架，或笔直射出的一柱光芒”**
* **考场推导**：
  * 屋顶承重柱 → **横梁**
  * 强光或激光射出 → **光柱、光束**
  * 脸上像阳光普照一样绽放开怀大笑（beam with joy/pride） → **眉开眼笑、欣喜地笑**

### 18. betray
* **常用义**：v. 背叛、出卖
* **底层骨架**：**“把原本藏在门后的机密/真相，彻底引渡交给了外人”**（*be-* + *tradere* 交付）
* **考场推导**：
  * 出卖战友或祖国 → **背叛**
  * 考研深层僻义修饰无意泄露真实内心（his trembling voice betrayed his fear / ignorance） → **无意中暴露、流露出（真实想法/缺陷）**

## 19 - 36

### 19. bid
* **常用义**：v./n. 出价、投标；努力、争取
* **底层骨架**：**“在拍卖场上大声喊出筹码，誓要争抢夺得目标”**
* **考场推导**：
  * 竞拍买房或竞标政府采购合同（bid for a contract） → **投标、竞价**
  * 政治或企业争权夺位发起猛攻（a bid for power / make a bid to do sth） → **企图、努力、争取**

### 20. blow
* **常用义**：v. 吹；吹动；n. 重击、沉重打击
* **考研高频搭配**：deal a heavy blow to...（给……以沉重打击）。

### 21. bold
* **常用义**：adj. 大胆的、勇猛的；醒目的；粗体的
* **底层骨架**：**“毫不畏缩探出头去，在视线中极度突出显眼”**
* **考场推导**：
  * 行事敢作敢当（a bold move/decision） → **果断大胆的**
  * 文字用重墨加黑印刷（bold type/face） → **粗体的、黑体的**

### 22. bother
* **常用义**：v. 打扰、烦扰；费心、操心；n. 麻烦
* **考研高频短语**：don't bother to do sth（不用费心去做某事）。

### 23. breath
* **常用义**：n. 呼吸；气息
* **考研高频短语**：out of breath（上气不接下气）、hold one's breath（屏息以待）。

### 24. breathe
* **常用义**：v. 呼吸
* **发音与词性注意**：breath 是名词（尾音轻辅音 /θ/），breathe 是动词（尾音浊辅音 /ð/）。

### 25. brush
* **常用义**：n. 刷子；v. 刷、擦过；轻触
* **考研高频短语**：
  * **brush aside** → 像掸灰尘一样随手把意见扫开 → **对……置之不理、不屑一顾**
  * **brush up on** → 把生锈的旧技能重新擦拭抛光 → **温习、重温**。

### 26. cable
* **常用义**：n. 缆绳；电缆；有线电视
* **考研高频搭配**：cable television（有线电视）、undersea cable（海底通信光缆）。

### 27. calendar
* **常用义**：n. 日历、日程表
* **考研微引申**：指年度重要活动安排节点（academic/parliamentary calendar 学期/议会会期日程）。

### 28. calm
* **常用义**：adj. 平静的、镇定的；v. 使平静
* **考研高频搭配**：keep/stay calm（保持镇定）、calm market fears（平息市场恐慌）。

### 29. cater
* **常用义**：v. 提供饮食、承办酒席；迎合
* **底层骨架**：**“把现成的饭菜端到客人跟前，百依百顺伺候其口味”**
* **考场推导**：商业或媒体根据受众偏好量身定制（cater to / for customer needs） → **迎合、满足……的需求**。

### 30. chamber
* **常用义**：n. 房间；议院；商会；腔室
* **底层骨架**：**“四周封严、供重要人物共商密谋的专属大厅”**
* **考场推导**：
  * 议会两院分支（upper/lower chamber 上议院/下议院） → **（立法机构的）院**
  * 工商业领袖聚集的权威团体（Chamber of Commerce） → **总商会**

### 31. chancellor
* **常用义**：n. （德国/奥地利）总理；（大学的）名誉校长；大法官
* **考研英国政治常客**：**Chancellor of the Exchequer** → **英国财政大臣**。

### 32. cheat
* **常用义**：v. 欺骗、作弊；n. 骗子
* **考研高频搭配**：cheat in an exam（考试作弊）、cheat consumers（欺诈消费者）。

### 33. cheque
* **常用义**：n. （英式）支票
* **美式拼写**：check。
* **考研短语**：blank cheque（空白支票 → 绝对无限授权）。

### 34. clone
* **常用义**：n. 克隆动物/细胞；仿制品；v. 无性繁殖、克隆
* **底层骨架**：源自希腊语 *klon*（小树枝） → 掐下一根嫩枝插扦长成一模一样的新植物。

### 35. clue
* **常用义**：n. 线索、提示
* **底层骨架**：古希腊神话阿里阿德涅引路逃出迷宫的毛线团（clew）。
* **考研口语化短语**：have no clue（毫无头绪、一无所知）。

### 36. coach
* **常用义**：n. 教练；长途大巴；火车车厢；v. 辅导
* **考研经济舱用法**：fly coach（乘坐经济舱出行）。

## 37 - 54

### 37. comply
* **常用义**：v. 遵从、依从、符合（法律/规章）（comply with）
* **底层骨架**：*com-* + *ple/fill*（填满） → 把官方各项指标条文全部填满打钩、无一遗漏。
* **派生**：compliance（n. 依从、合规，如 regulatory compliance 监管合规）。

### 38. correlate
* **常用义**：v. 相互关联、相互影响；显示相互关联（correlate with）
* **底层骨架**：*cor-*（共同）+ *relate*（联系） → 两个变量步调共振，一动皆动。
* **考研统计学大词**：correlation（n. 相关性；注意与 causation 因果性区分）。

### 39. courtesy
* **常用义**：n. 礼貌、谦恭有礼；客套举止
* **词源**：源自 court（宫廷礼仪）。
* **考研高频短语**：
  * **courtesy of...** → 由……免费提供、承蒙……的慷慨资助
  * by courtesy of（蒙受……允许）。

### 40. crack
* **常用义**：v. （使）破裂、砸碎；n. 裂缝；重击
* **底层骨架**：**“硬物受外力砸出一道细密裂隙并发出脆响”**
* **考场推导**：
  * 瓷器或冰面开裂 → **裂纹、缝隙**
  * 刑侦破译密码或专家攻克棘手难题（crack a code / crack a hard case） → 找出突破缺口 → **破译、攻克、破解**
  * 考研打击违法大词：**crack down on...** → 重拳猛砸下去 → **严厉打击、镇压（犯罪/违规）**

### 41. creep
* **常用义**：v. 蹑手蹑脚缓慢爬行；悄然潜入
* **底层骨架**：**“趴在地上像虫子一样极其缓慢无声地向前挪动”**
* **考场推导**：
  * 动作极轻爬行 → **爬、缓慢前行**
  * 坏习惯或错误悄无声息地溜进系统（errors creep into the system） → **不知不觉潜入、蔓延**
  * 成本或通胀不知不觉逐步攀升（creep up） → **渐渐上涨、缓慢攀升**

### 42. crowd
* **常用义**：n. 人群、群众；v. 挤满、聚集
* **考研高频短语**：crowd into（涌入）、crowd out（排挤挤走，如经济学 crowding-out effect 挤出效应）。

### 43. cucumber
* **常用义**：n. 黄瓜
* **考研心理学常用习语**：**as cool as a cucumber** → 黄瓜天生清凉带露 → **泰然自若、极其从容冷静**。

### 44. cue
* **常用义**：n. 暗示、提示信号；台球杆；v. 给……提示
* **考研高频短语**：**take one's cue from sb** → 看着台下提示员的暗号照着演 → **效仿某人、听从某人的指挥**。

### 45. dare
* **常用义**：v. 敢、胆敢（dare to do / dare do）；敢于面对
* **考研短语**：How dare you...（你竟敢……）、I dare say（我想、很可能）。

### 46. dean
* **常用义**：n. （大学的）学院院长、系主任；教长
* **考研高频搭配**：dean of the law school（法学院院长）。

### 47. decay
* **常用义**：v./n. 腐烂、腐朽；衰退、瓦解
* **底层骨架**：*de-*（向下）+ *cad/cay*（掉落） → 像秋天烂落的果子一样逐渐溃散坏掉。
* **考场推导**：
  * 牙齿或木质腐烂 → **蛀牙、腐蚀**
  * 城市主城区或帝国衰败（urban decay） → **（社会/经济）衰败、崩坏**

### 48. decorate
* **常用义**：v. 装饰、装潢；授予勋章
* **底层骨架**：词根 *decor-*（体面、恰当） → 让外貌变得体体面面。
* **考场推导**：军人在战场建功被挂上勋章（be decorated for bravery） → **授勋表彰**。

### 49. deem
* **常用义**：v. 认为、视为、判定（等同于 consider / regard as）
* **底层骨架**：古英语中法官坐堂经过深思熟虑做出判决。
* **考研正式公文句型**：deem sth necessary / appropriate（认为某事完全有必要/妥当）。

### 50. delight
* **常用义**：n. 欣喜、极大的快乐；令人高兴的事；v. 使高兴
* **派生**：delighted（adj. 高兴的）、delightful（adj. 令人心旷神怡的）。

### 51. deploy
* **常用义**：v. 部署（军队/兵力）；有效利用、调配（资源）
* **底层骨架**：*dis-* + *ploy/plic*（折叠） → 把折叠收好的军团在平原阵地上全部铺排展开。
* **考场推导**：
  * 军队布防排开 → **部署、调派**
  * 企业把手头的资金、人才技能全部调度到一线去（deploy capital / skills） → **调动、充分利用、运用**

### 52. diligent
* **常用义**：adj. 勤勉的、孜孜不倦的
* **构词**：*dis-* + *leg*（挑选） → 对手头工作全神贯注精挑细选不懈怠。
* **考研高频搭配**：diligent investigation/effort（持之以恒的调查/勤勉的努力）。

### 53. disappoint
* **常用义**：v. 使失望、使破灭；使落空
* **底层骨架**：*dis-*（取消）+ *appoint*（指定/约定） → 单方面把约好的事情撤销晃点人。

### 54. discard
* **常用义**：v. 丢弃、抛弃；n. 弃牌、被废弃物
* **底层骨架**：*dis-*（剥离）+ *card*（卡牌） → 打牌时把抓在手里的无用废牌直接扔进废牌堆。
* **考研同义替换**：abandon, throw away。

## 55 - 70

### 55. disguise
* **常用义**：v. 伪装、乔装；掩饰；n. 伪装物
* **底层骨架**：*dis-*（改变/脱离）+ *guise*（风度外观） → 彻底改换一身行头让人辨认不出来。
* **考研高频搭配**：disguise one's feelings/intentions（掩盖真实情感/意图）、a blessing in disguise（因祸得福/塞翁失马）。

### 56. dislike
* **常用义**：v./n. 不喜欢、厌恶
* **反义词**：like。

### 57. doom
* **常用义**：n. 厄运、死劫；v. 注定失败/毁灭（be doomed to）
* **底层骨架**：**“上天神明对罪恶降下的末日死刑审判”**
* **考场推导**：
  * 绝望的终局 → **灭顶之灾、厄运**
  * 方案或改革注定破产（be doomed to failure） → **注定（失败/灭亡）**

### 58. drought
* **常用义**：n. 干旱；持久的旱灾
* **底层骨架**：与 dry（干燥）同源 → 大地水汽蒸干彻底干裂。
* **考研比喻引申**：某事物的长期极度匮乏（a talent/funding drought 人才荒/资金匮乏）。

### 59. eager
* **常用义**：adj. 热切的、渴望的（eager to do / eager for）
* **同义替换**：keen, anxious, enthusiastic。

### 60. edge
* **常用义**：n. 边缘；刀口；v. 微移
* **底层骨架**：**“刀锋劈开的最锋利处，引申为快人半个刀位的领先距离”**
* **考场推导**：
  * 悬崖或桌沿 → **边缘**
  * 商业竞争中比对手锋利一丝的微弱胜算（have a competitive edge over...） → **竞争优势、上风**
  * 短语陷入崩溃边缘（on the edge of a nervous breakdown） → **濒临（危险/崩溃）**
  * 动词谨慎一点一点挪动（edge closer to the target） → **徐徐移动、悄悄逼近**

### 61. elementary
* **常用义**：adj. 初步的、基础的；小学的
* **考研高频搭配**：elementary school（小学）、elementary level（初级水平）。

### 62. embryo
* **常用义**：n. 胚胎；萌芽阶段的事物；adj. 胚胎的
* **底层骨架**：在肚子里正在肿胀生发出来的第一颗生命小芽。
* **考研高频比喻短语**：**in embryo** → 计划尚处于襁褓起步之初 → **在萌芽期、在初创阶段**。

### 63. emergency
* **常用义**：n. 紧急情况、突发事件；adj. 紧急备用的
* **底层骨架**：*emerge*（冒头浮现） → 毫无预兆突然冒出来的突发险情。
* **考研高频搭配**：emergency measures/room (ER)（紧急举措/急诊室）。

### 64. engagement
* **常用义**：n. 订婚；约会；参与、深度涉足；交战
* **底层骨架**：两副齿轮咬死在一起，或者将全部注意力投身进去。
* **考场推导**：
  * 婚姻盟约 → **订婚**
  * 读者、用户或公民对公共事务的高度互动投入（civic/customer engagement） → **参与度、投入度、积极互动**

### 65. enrich
* **常用义**：v. 使富足；使内容充实丰富；增加营养
* **构词**：*en-*（使）+ *rich*（富有）。
* **考研高频搭配**：enrich one's life/experience（丰富某人的生活/履历）。

### 66. enterprise
* **常用义**：n. 公司、企业；事业；进取心
* **底层骨架**：*enter-*（在中间）+ *prise/prehend*（抓取） → 敢于下手抓下重大使命的开拓之举。
* **考场推导**：
  * 商业实体（state-owned / private enterprise） → **企业、公司**
  * 敢冒风险、迎难而上的企业家品格（show free enterprise） → **进取心、事业心**

### 67. enthusiastic
* **常用义**：adj. 热情的、热心的（enthusiastic about）
* **派生**：enthusiasm（n. 热情）。

### 68. equip
* **常用义**：v. 装备、配备；使具备能力（equip sb with/for）
* **底层骨架**：水手扬帆出海前，把全套缆绳工具搬齐上船。
* **考研高频搭配**：equip students for the future workforce（让学生具备应对未来职场的能力）。

### 69. excitement
* **常用义**：n. 兴奋、激动；引起激动的事物
* **反义词**：boredom（厌倦、无聊）。

### 70. exploit
* **常用义**：v. 剥削；充分开发利用；n. 英勇事迹、辉煌功绩
* **底层骨架**：**“把卷起来的布匹全面展开摊平，将内含的全部能量榨取发挥到极致”**（*ex-* + *plic* 折叠）
* **考场推导**：
  * 资本家压榨雇员血汗（exploit workers） → **剥削、压榨**
  * 科学产业充分发掘利用矿脉或技术红利（exploit natural resources / opportunities） → **开发、充分利用（褒义/中性）**
  * 名词指英雄在沙场立下的战功（military exploits） → **英勇战绩、壮举**
