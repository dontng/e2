# 考研英语二核心词汇手册 · Word List 26（全 28 词）

---

## 01 - 14

### 01. breakdown
* **常用义**：n. 故障、损坏；破裂、瘫痪；细目分类
* **拆分**：*break*（破裂）+ *down*（向下倒塌） → 结构散架瘫在地上。
* **考场推导**：
  * 汽车或机器出故障停摆 → **故障、机能停滞**
  * 谈判破裂或神经崩溃（a nervous breakdown / breakdown in talks） → **破裂、精神崩溃**
  * 统计数据按条目逐项拆分剖析（a detailed breakdown of costs） → **明细表、细目分类**

### 02. bypass
* **常用义**：n. 旁路、绕行道路；v. 绕过、绕开；避开（规章/程序）
* **拆分**：*by*（侧面）+ *pass*（通过） → 不走正门主道，从侧面通道溜过去。
* **考场推导**：
  * 城市环线避开拥堵 → **旁道、绕行路**
  * 绕过繁文缛节官僚程序（bypass normal procedures / regulations） → **越过、规避、绕开**

### 03. countryside
* **常用义**：n. 农村、乡下；乡村地区
* **拆分**：*country*（乡野）+ *side*（一侧/区域）。
* **考研高频搭配**：rural countryside（乡村地区）。

### 04. cyberspace
* **常用义**：n. 网络空间、赛博空间
* **拆分**：*cyber-*（计算机控制的/赛博的）+ *space*（空间）。
* **考研高频搭配**：cyberspace security（网络空间安全）。

### 05. drawback
* **常用义**：n. 缺点、劣势、不利条件
* **底层骨架**：*draw*（拉）+ *back*（向后） → 正在向前迈步时在背后猛扯后腿。
* **考研同义替换**：disadvantage, shortcoming, defect。

### 06. eyebrow
* **常用义**：n. 眉毛
* **考研核心神态习语**：**raise eyebrows** → 挑起眉毛 → **引起质疑、令人侧目震惊、招致非议**。

### 07. foremost
* **常用义**：adj. 最重要的、首要的；最著名的
* **拆分**：*fore*（在前）+ *most*（最） → 稳稳排在全天下最前列。
* **考研绝杀固定短语**：**first and foremost** → **首先、最首要的是**。

### 08. forthcoming
* **常用义**：adj. 即将到来的；现成的、可得到的；乐意提供信息的
* **底层骨架**：*forth*（向前）+ *coming*（走来） → 迈开步子主动走上前台。
* **考场推导**：
  * 即将举办的大会或出版物（forthcoming elections / book） → **即将到来的、即将来临的**
  * 所需资金已就位（financial support was not forthcoming） → **现成的、可获取的**
  * 面对采访坦率直言（be forthcoming about the facts） → **坦率的、乐于提供情况的**

### 09. headquarters
* **常用义**：n. 总部、总公司、总指挥部
* **拆分**：*head*（首脑）+ *quarters*（营房住处） → 司令官集中坐堂发号施令的中枢。
* **语法点**：单复数同形，作主语时谓语动词单复数均可。

### 10. housework
* **常用义**：n. 家务劳动、家务事
* **语法点**：不可数名词，不能加复数 -s（做家务用 do the housework）。

### 11. lifetime
* **常用义**：n. 一生、终生；使用寿命；adj. 一辈子的
* **考研高频搭配**：lifetime earnings（一生的总收入）、a chance of a lifetime（千载难逢的绝佳良机）。

### 12. masterpiece
* **常用义**：n. 杰作、代表作、名著
* **拆分**：*master*（大师）+ *piece*（单件作品） → 大师一生心血打磨出的巅峰之作。

### 13. meantime
* **常用义**：n. 其间、其时；adv. 与此同时（等同于 meanwhile）
* **考研核心逻辑短语**：**in the meantime** → 在此期间、与此同时。

### 14. nearby
* **常用义**：adj. 附近的、邻近的；adv. 在附近
* **考研高频搭配**：nearby towns/residents（邻近城镇/附近居民）。

## 15 - 28

### 15. nightmare
* **常用义**：n. 噩梦；梦魇般可怕的经历
* **底层骨架**：*night*（夜晚）+ *mare*（古英语中夜间压在人胸口的梦魔）。
* **考研微引申**：极度混乱糟糕的现实烂摊子（a bureaucratic nightmare 官僚繁文缛节带来的可怕噩梦）。

### 16. outbreak
* **常用义**：n. （战争、疾病、暴力等坏事的）爆发、突然发作
* **拆分**：*out*（向外）+ *break*（破裂冲出） → 蓄积的破坏力量冲破牢笼瞬间炸开。
* **考研高频搭配**：the outbreak of war/flu（战争爆发/流感大流行）。

### 17. outrage
* **常用义**：n. 愤怒、义愤；暴行；v. 使震怒、激怒
* **底层骨架**：超出一切公理和道德底线的恶劣行径（*out* 超出 + 词源并非 rage 而是法语 *outré* 过分）。
* **考研高频搭配**：cause/spark public outrage（引起公愤/激起全社会义愤）。

### 18. outset
* **常用义**：n. 开端、开始
* **底层骨架**：*out* + *set*（启程出发） → 拔腿迈向征程的第一步。
* **考研核心固定短语**：**at/from the outset** → **从一开始、从起初阶段**。

### 19. overhead
* **常用义**：adv. 在头顶上；adj. 头顶上的；地面以上的；n. 运营经常性费用
* **考场推导**：
  * 飞机飞过头顶（fly overhead） → **在头顶上**
  * 企业只要开门就必须按月承担的固定房租水电人工底盘（overhead costs / reduce overheads） → **管理杂费、日常营运成本**

### 20. roundabout
* **常用义**：n. （道路交通）环岛、回旋处；adj. 拐弯抹角的、迂回的
* **底层骨架**：不走直线笔直切入，而是绕着圈子走走停停。
* **考场推导**：谈吐或行事不直截了当（in a roundabout way） → **拐弯抹角地、迂回曲折地**。

### 21. shortcoming
* **常用义**：n. （常用复数 shortcomings）缺点、短处、短板
* **底层骨架**：*short*（不足）+ *coming*（到来） → 距离达标门槛还差上一大截。
* **考研同义替换**：defect, flaw, limitation, drawback。

### 22. shorthand
* **常用义**：n. 速记、速记法；简略表达方式、代名词
* **底层骨架**：用简化的缩写符号代替长篇文字。
* **考研社科引申**：用某个标签直接代表全套复杂概念（used as shorthand for...） → **……的代名词、简写**。

### 23. sometime
* **常用义**：adv. （过去或未来的）某个时候；adj. 曾经的、从前的
* **辨析**：
  * **sometime**：某个未知的时间点（I will call you sometime next week）
  * **some time**：一段具体充裕的时间（take some time）
  * **sometimes**：频度副词，有时、偶尔。

### 24. spacecraft
* **常用义**：n. 航天器、宇宙飞船
* **拆分**：*space*（太空）+ *craft*（飞行载具）。
* **语法点**：单复数同形（one spacecraft / several spacecraft）。

### 25. upright
* **常用义**：adj. 挺直竖立的；垂直的；正直诚实的；adv. 挺直地
* **底层骨架**：*up*（向上）+ *right*（端正笔直） → 脊梁骨笔直挺立，不弯腰屈服。
* **考场推导**：人品刚正不阿没有污点（an upright citizen） → **正直规矩的、诚实的**。

### 26. upstairs
* **常用义**：adv. 在楼上、往楼上；adj. 楼上的；n. 楼上
* **反义词**：downstairs（在楼下/往楼下）。

### 27. viewpoint
* **常用义**：n. 观点、视角；观察点
* **底层骨架**：*view*（视野）+ *point*（站位点） → 双脚所站立用来观察大局的特定方位。
* **考研同义替换**：perspective, standpoint, angle。

### 28. warehouse
* **常用义**：n. 仓库、货栈；批发商行
* **拆分**：*ware*（货物/器具）+ *house*（房屋） → 专供大批量堆放货物的仓房。
* **考研高频搭配**：warehouse management（仓储管理）。
