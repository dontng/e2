# 英语二写作：从真题练出下一句

当前材料分为Part A小作文与Part B大作文，年份均以2010—2026为主线。最小训练单位是一句具体回答：读题后先决定写什么，接着说明它从哪里来、怎样接下一句；中文先练内容，英语随后练表达与限时成文。目标分别为小作文8/10、冲9/10，大作文12/15、冲13—14/15；示范自审与实际阅卷、学习者掌握程度分别记录。

## 怎样进入一次练习

先看当前题的一句生成过程，移开答案后做底部小变式。没有内容就修内容提取，有内容却说不清就修眼前关系；只增加当前需要的一步，不要求每个年份恰好新增一个知识点。保存首次输出、用时和一个卡住之处，不以文件数量或照抄范文证明学会。

中文起步可先给一句30—60秒，逐步减少思考时间；这是训练过渡，考场不新增中文腹稿流程。进入英文后重新查任务、词数、准确性、表达变化与组织，再在完整模考中验证时间。未看答案的新题与首次稿更有判断价值，见过答案的同题只能算复测；当前教学已写出，不记录学习者已经掌握。
