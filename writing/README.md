# 英语二写作应试准备与训练总入口（65+ 保分线）

> **定位**：专治考场大脑空白、无从下笔，同时正面应对 2021—2026（特别是 2024—2026）真题的“具体情景化、微观日常化、静态多选图表化”新趋势。  
> **目标分**：对齐 [`plan/1103-target-65-strategy-and-plan.md`](../plan/1103-target-65-strategy-and-plan.md)，大小作文合计 **25 分**，先稳保 **16–18 分**，再冲 **19–20 分**，托起全卷 **65+**。

## 核心原则（告别过去两种走不通的路）

1. **不背 18 篇长范文，也不读 34 课纯中文理论**：只背**高频核心词块 + 极简模块化功能句骨架**，把精力全部砸在“限时写出无大错的英文”上。
2. **不把“想内容、搭句型、拼单词”混在一起**：先练死单词与句子底牌（解决拼写与句法），再用固定发问口令提取内容（解决没话写），最后 40 分钟联写验收（解决考场死机）。
3. **先求 100% 写得出且切题，再求表达稳健**：英语二写作阅卷是整体分档——**要点齐全 + 数据准确 + 逻辑连贯 + 无致命语法/拼写错**，用中学及四级核心词就能稳稳拿到 7–8 分（小）与 10–12 分（大）。
