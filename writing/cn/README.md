# 中文写作教学：2010—2026

这里管理中文内容生成阶段的材料。`10a—26a`中的a表示Part A小作文，`10b—26b`中的b表示Part B大作文，数字对应2010—2026。两条课程各从2010起步，后课逐步复用前课已经演示的判断和内容关系；不是把十七篇完整模板按年份排好让你背。

每课的“这一处可以写”下面单独显示实际中文句子，普通段落解释它怎样从题目或前一句产生。完整回答与练习参考同样放在引用块，重点要求单独加粗；长中文可自然换行。每次先练眼前一句和底部的小变式，保留首次输出及卡住的一处，不把读过材料记录成已经掌握。

## 当前学习与后续验证

先从当前课程的2010课开始，旧判断不足就在眼前句补，不要求反复读完整材料库。目标分数要以未看答案的新题、首次英文稿、实际用时和盲评分逐步核验。教学示范、独立生成、限时成文是不同阶段；当前尚未收到这些课的首次练习，不能记录已经教会。
