# 中文小作文教学：2010—2026

这里存放中文内容生成的阶段教学，文件名 10a—26a 对应 2010—2026。先练读题后怎样找一句具体回答、怎样接下一句，暂不把这些材料当作已经完成的英语作文。英语词汇、句式、字数和最终评分另行训练。

从 [10a.md](./10a.md) 开始，后课明确复用前课的内容动作，并讲清本题新增处。每课的 **“这一处可以写”** 下方是单独显示的句子；普通段落解释句子为什么这样产生。完整回答和练习参考也单独显示，便于先读、移开后重写，再回来核对。

## 复盘与后续材料

每次只练当前小变化，保留首次中文回答及卡住的一处；不能用照抄完整答案证明独立生成。已经教过的内容不等于已经掌握，后课遇到同一关系仍卡住时，回到眼前句子修，不要求重读全部前课。最终九分目标需要英语成文与限时输出的证据。

[中文任务与内容题库](../part-a-cn-papers.md) 保留核对来源，[英文审核稿](../part-a-score-audit.md) 留待后续阶段；[原 playbook](../part-a-playbook.md) 按用户要求保留，当前逐课学习从本目录进入。目录调整只管理这些中文课，没有改动原有主稿或阅读教学。
