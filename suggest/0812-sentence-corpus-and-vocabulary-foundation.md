# 每日一句语料与词汇基础建设建议

> 建议生成时间：2026-08-12 02:40:25 CST（Asia/Shanghai）
>
> 讨论对象：`src-we/2025/` 的 242 篇每日一句、当前 `src/` 的闭卷翻译与批改流程，以及“怎样把单词真正学扎实”这一长期目标。

> [!NOTE]
> 本文保留的是跨年去重前对 2025 年 242 篇原始材料的分析。2025 与 2026 去重后的当前规模、词汇统计和考纲覆盖，以 [src-we 跨年去重与词汇覆盖评估](0812-src-we-dedup-and-vocabulary-coverage.md) 为准。

## 核心结论

当前方向没有走错。

从真题句子出发，先独立翻译，再用批改暴露不会、误译、形近词误判、义项误判和搭配误判，比拿着一张词表反复阅读更能发现真实问题。它已经完成了词汇学习中非常重要的一步：**选择真正需要学的词，并把词放回有意义的语言环境中。**

但这套流程目前更擅长“发现和解释”，还没有稳定完成“延迟后再次提取”。单词当天看懂、笔记写得完整，不等于几天后在新句子里能自动认出。问题不在于输入方式完全错误，而在于学习链条停在了第一次输入和当日理解。

更准确的判断是：

> 被动翻词书不可靠；只做一次语境输入也不可靠。真正可靠的是：真实问题触发的输入，加上间隔后的主动提取和跨语境迁移。

因此，不需要推翻 `src/`，也不需要另建一个巨大的背词项目。需要做的是在现有 daily 后面补上一个轻量、可执行的复测闭环。

## 一、2025 每日一句已经形成怎样的语料

### 1. 完整度与规模

`src-we/2025/` 实际保存 242 篇，覆盖 Day 1—252，完整率约为 96%。缺少：

```text
Day 4、6、13、22、24、26、28、30、32、144
```

这个缺口不影响它作为句法训练库使用。除非缺失 HTML 已经在手边，否则没有必要为了凑齐数字专门追索。

242 个原句合计约：

| 项目 | 数量 |
|---|---:|
| 原句总词数 | 9,330 |
| 不同词形 | 约 3,003 |
| 只出现一次的词形 | 约 1,977 |
| 生词栏目词条 | 约 1,712 |
| 简单规范化后的不同词或词组 | 约 1,504 |

平均每句约 38.6 词，中位数为 37 词，最长为 98 词。

这里的“不同词形”没有做严格词元化，包含时态、复数、派生形式和部分专名；“不同词或词组”也只是根据生词栏目做的简单规范化。因此这些数字用来判断规模和重复程度，不应当当作精确词汇量测验。

### 2. 句法覆盖

按讲解中实际出现的关键词统计，主要结构包括：

| 结构 | 涉及篇数 |
|---|---:|

| 平行、并列结构 | 75 |
| 状语从句 | 64 |
| 非谓语 | 62 |
| 简化、去修饰找核心 | 56 |
| 嵌套结构 | 52 |
| 分裂结构 | 24 |
| 同位语从句 | 23 |
| 省略 | 21 |
| 主语从句 | 9 |
| 倒装 | 9 |
| 强调句 | 9 |
| 形式主语、形式宾语 | 9 |
| 比较结构 | 5 |
| 虚拟语气 | 1 |

它对“寻找谓语—确定主句—识别从句—去掉修饰找核心”覆盖很好，尤其适合解决每个词似乎都认识、却不知道谁修饰谁的问题。

它不是完整语法课程。否定范围、情态强弱、比较关系、信息焦点、跨句指代和段落逻辑覆盖较弱。

### 3. 真题来源构成

| 来源 | 篇数 |
|---|---:|
| 明确标注英一 | 105 |
| 明确标注英二 | 87 |
| 2002—2009 旧题，未区分英一英二 | 50 |

真正直接属于英二的只有约 36%。原句年份覆盖 2002—2023，没有2024和2025真题句源。

因此，这套材料适合做高密度句法库，不适合代替2016—2025十套完整英语二真题。

## 二、这个语料群的真正价值

### 1. 对句法训练：量已经足够

242 个经过人为挑选的长难句，足够让常见结构多次出现。它们不是普通英语的随机样本，而是高句法密度样本：多谓语、多层从句、长修饰链、平行和嵌套明显多于一般文本。

如果每句真正完成以下动作：

1. 找出限定谓语；
2. 划分主句和从句；
3. 标明修饰对象；
4. 删除修饰，保留句子核心；
5. 恢复各层语义关系；
6. 独立翻译并核对；

那么242句已经足够形成稳定的长难句操作经验。继续收集同类句子的价值，低于把已有句子接回段落和题目。

### 2. 对词汇发现：价值较高

每日一句能暴露词汇表不容易暴露的问题：

- 单词完全不认识；
- 看起来认识，放在句中却取错义项；
- 把 `novel` 看成 `noble` 一类的词形误认；
- 单词认识，但 `compare A with B`、`sort out how` 等整体没有合读；
- 知道中文释义，却没有保住搭配边界；
- 认识名词，不认识同词族的形容词或动词；
- 当天能认出，隔几天在新句中又失效。

这些问题比“今天背了多少个词”更接近考试中的真实失分原因。

### 3. 对词汇巩固：现有材料本身不够

约3,003种词形中，约1,977种只出现一次，占约66%。这说明材料的词汇广度很大，但自然复现不足。

读完242句会让人见过很多词，却不会自动让这些词进入长期记忆。单次语境能够帮助理解，却不能替代后续提取。

这也是“明明背过，考试又不认识”的根本原因之一：学习时完成的是重新阅读，考试要求的是在没有答案提示时，从词形和上下文中主动取回意义。

## 三、什么才叫“单词扎实”

“扎实”不是看到中文以后觉得熟，也不是能够背出一串词典释义。对英语二而言，词汇掌握至少有四个层级：

| 层级 | 表现 |
|---|---|
| 0 未知 | 看见词形没有稳定方向 |
| 1 提示后认识 | 看见解释觉得“我背过” |
| 2 语境识别 | 在真题句子中无需查阅，能迅速取得正确方向 |
| 3 精确调用 | 能保住本句义、搭配、词性和语义范围 |
| 4 主动产出 | 翻译或写作时能自己提取并正确使用 |

英语二不要求把所有单词都练到第4层。

- 大部分阅读词汇达到第2层即可；
- 会决定句子方向的核心词、熟词僻义和固定搭配需要达到第3层；
- 真正常用于翻译表达和作文的少量词块才需要达到第4层。

如果要求1,500个生词全部做到主动产出，成本极高，也不符合试卷需要。

一个可操作的“掌握”标准是：

> 在至少三个相隔的日期中，不看笔记，能够在原句或新语境中迅速取得正确方向；其中至少一次不是原句复现。

当天连续答对三遍不能替代这个标准，因为那主要反映短时记忆。

### 扎实基础需要三个不同规模的词汇池

只靠错误触发也有盲区：有些基础词尚未在 daily 中出现，有些词虽然这次靠上下文猜对，实际词形—意义连接仍不稳定。因此，“不背整张词表”不等于完全不要覆盖清单。

更合理的是把词汇分成三个不同目标的池：

| 词汇池 | 来源 | 目标 | 处理深度 |
|---|---|---|---|
| 覆盖池 | 2016—2025完整真题、可信核心词表 | 看见能迅速取得基本方向 | 英文—核心义快速提取，不写长笔记 |
| 问题池 | daily 翻译和做题暴露的真实错误 | 在句中准确识别义项、词性和搭配 | 保存错误、原文词块、辨别线索和复测 |
| 产出池 | 翻译重组和作文可复用表达 | 能主动调用 | 少量反向提取、造句和改写 |

覆盖池解决“还有大量基础词从未遇到”的问题；问题池解决“背过却在句中失效”的问题；产出池解决“认识但不会用”的问题。

三个池不能平均用力。覆盖池可以较大但处理要轻；问题池规模应当受控但处理要深；产出池必须最小，只保留真正值得主动使用的词块。

因此，词表本身并非无用。它适合做覆盖地图和快速自测，不适合让每个词都生成词根、例句、易混词和长篇笔记。真题和 daily 决定哪些词从覆盖池晋级到问题池。

## 四、现有 `src/` 方法为什么有价值

`src/` 当前执行的是：真题句子输入、独立翻译、差异批改、核心复盘、问题词汇、问题短语和最小迁移。

这条路径的主要优点是：

### 1. 选词来自真实失败

现行 `STANDARD.md` 已经规定：词汇区只收翻译暴露的问题词，不因为原句出现就收，不凑数。这比按教师词表平均用力更合理。

### 2. 翻译是一种无提示提取

独立翻译会迫使学习者同时处理词形、语义、结构和指代。它能揭示“单独看单词认识，进入句子就不会”的假熟悉。

### 3. 批改保留了错误路径

记录 `novel` 被看成 `noble`、`virtual` 被固定成“虚拟的”、`they` 回指错误，比重新抄一遍正确释义更有价值。下次需要防范的不是抽象的“词汇不好”，而是具体误判机制。

### 4. 词和短语已经分开

“单词认识但整体读不懂”通常是搭配问题。把 Vocab 与 Phrases 分开，能够避免所有问题都被归入“单词量不够”。

### 5. 最小迁移方向正确

用一个同结构但不同内容的新句子检验，能够区分“记住了原答案”和“掌握了处理方法”。

## 五、现有方法还缺什么

### 1. 缺少延迟复测

一篇 daily 完成以后，词汇讲解通常停留在原文件里。第二天进入新句子，旧词是否还能取回，没有成为固定动作。

### 2. 解释可能过重，提取可能过轻

词根、核心意象、三个例句和易混词都可能有价值，但如果每个词都展开，容易出现“笔记越来越漂亮，复测越来越少”。

解释的目的应当是帮助下一次取回，不是形成词汇百科。

### 3. 例句容易被被动阅读

直接展示三个例句时，学习者可能只是读懂。真正需要的是先遮住目标词或释义，让学习者作答，再展示答案。

### 4. 缺少掌握状态

当前文件能说明某天学过什么，却不一定说明：

- 哪些词仍然失败；
- 哪些词已在不同日期成功三次；
- 哪些词只会原句；
- 哪些词已经能迁移到新语境；
- 哪些词应该退出复习队列。

## 六、建议采用的完整学习闭环

### 阶段一：真实问题触发

继续保持现有 daily，不先看讲解，完成句子拆解和翻译。

只有出现以下情况，词或短语才进入主动复习：

- 完全不会；
- 义项方向错；
- 词形认错；
- 搭配没有合读；
- 明显停顿，影响整句理解；
- 以前学过，但这次没有调用出来；
- 对翻译或写作有明显复用价值。

仅仅因为教师词表列出，不构成晋级理由。

### 阶段二：建立最小词条

每个问题词先只保留五项：

```md
**`virtual`** adj.

- 本句义：事实上几乎等同于
- 原文词块：a virtual necessity
- 我的错误：固定译成“虚拟的”
- 辨别线索：后接 necessity / certainty / standstill 时检查“实际近乎”义
- 下次测试：换一个新名词搭配判断义项
```

词根、核心意象、例句和易混词只在确实能解决该错误时加入。没有帮助就不展开。

### 阶段三：安排间隔提取

可以先采用简单的经验间隔：

```text
当天 → 次日 → 第3天 → 第7天 → 第14天 → 第30天
```

这不是所有单词都必须完整走六次。答对且迅速的词延长间隔；答错、犹豫或依赖原句的词回到短间隔。

间隔学习的关键不是机械遵守某一组天数，而是让下一次提取发生在答案已经不再停留于工作记忆、但仍有机会成功的时候。

### 阶段四：每次测试不同能力

同一个词至少需要经历以下几类测试：

1. **词形到本句义**：看到英文，给出当前语境方向；
2. **语境到词形**：给出挖空句或中文方向，补出目标词；
3. **搭配合读**：判断目标词和哪些成分构成整体；
4. **易混辨别**：在真实会混淆的两个词之间选择；
5. **新语境迁移**：换一个句子，判断是否仍能取得正确意义。

阅读词汇不必全部做中译英。只有准备进入翻译表达或作文的词块，才提高到主动产出测试。

### 阶段五：退出复习队列

满足以下条件后可以降级或退出：

- 跨至少14天成功提取三次；
- 至少一次出现在新语境；
- 没有依赖中文提示；
- 阅读时不再造成明显停顿；
- 搭配和义项方向稳定。

退出不表示永远不会忘，而是把复习资源让给仍然会导致失分的词。

## 七、每日执行不应变成第二份重任务

建议继续每天一个真实句子，但限制新增主动词汇数量。

一个可执行的日常结构是：

1. 闭卷处理当天句子；
2. 完成批改；
3. 从错误中晋级最多3—5个词或短语；
4. 复测当天到期的旧项目；
5. 用一个新句子测试当天最重要的结构或词义；
6. 记录成功、犹豫或失败，不继续写长解释。

如果当天暴露10个词，不必10个都进入主动池。应优先选择：

- 决定句子方向的词；
- 真题中可能复现的词；
- 熟词僻义；
- 固定搭配；
- 已经反复出错的词；
- 翻译和写作可以调用的词块。

其他项目留在原句中作为识别材料即可。

## 八、怎样使用 2025 的 242 句

不要把它重新变成242天的新任务，也不要批量重写全部文件。

建议分为两层：

### 核心层：87篇明确英二

优先作为句法诊断和迁移题库。当前 daily 暴露某类问题时，从这87篇中选择同类结构做延迟测试。

### 补充层：105篇英一和50篇旧题

只在核心层样本不足，或者需要验证某个词、搭配和句法能否跨语境迁移时调用。

242句最有价值的新角色不是“继续提供新词”，而是：

> 给当前 `src/` 已经学过的词和结构提供陌生、延迟、可验证的复测环境。

如果某个词只在原 daily 中会，换到2025句库就失败，说明它还没有真正掌握。

## 九、怎样看待“核心词带背”图片

已检查的2006 Text 1样本包含19组核心概念，扩展为41个词形。它的优点是按原文和词族整理；缺点是偏向“英文＋音标＋中文释义＋派生词”，缺少原文搭配、具体义项和后续提取。

这类图片可以作为候选词索引，不能直接成为主动背诵清单。

使用原则：

- 真题处理中确实造成困难，才晋级；
- 只为凑齐词族的低频派生词只需识别；
- 原词应恢复为原文词块；
- 不处理全部146张图片；
- 不为图片单独建立另一套词汇主线。

## 十、GPT 应该承担什么角色

GPT 可以帮助诊断和生成测试，但不能替学习者完成提取。

### 适合交给 GPT

- 判断错译来自词义、词形、结构还是指代；
- 给出最小、可迁移的解释；
- 生成一个不复刻原句的新语境；
- 把例句改成挖空题；
- 对比真正会混淆的两个词；
- 根据历史错误出短测；
- 检查翻译是否保住搭配和语义范围。

### 不适合交给 GPT

- 一开始就输出长篇词源讲解；
- 为每个原句生成十几个相关词；
- 用“看懂了解释”代替闭卷作答；
- 让云端对话成为唯一记录来源；
- 不经过真实真题失败就批量制造词汇任务。

可以采用这样的复测提示：

```text
不要先解释，也不要展示答案。
请用一个与原句主题不同的新句子测试 virtual 的义项。
先让我判断并翻译；我回答后，再指出我是词义错误、搭配错误还是结构错误。
如果答对，再测试一次 virtual 与 virtual reality 中含义的区别。
```

项目仓库应当继续作为事实来源：保存原句、原始错误、批改和最终结论。GPT 负责当场互动，不承担长期记忆本身。

## 十一、判断方案是否有效的指标

不要以这些指标为主：

- 今天新增了多少词；
- 笔记写了多少行；
- 一共收藏了多少句；
- 当天看答案后是否觉得理解。

应该观察：

- 延迟一天后能否无提示取回；
- 一周后能否在新句中认出；
- 同一错误是否在后续真题再次发生；
- 阅读是否仍会被该词打断；
- 翻译能否保住正确义项和搭配；
- 以前学过的资源能否在新年份被调用。

这与仓库已经确定的年度递归口径一致：继承并调用、继承但失效、可组合解决和本年新增。

## 十二、建议先执行四周，不开发新系统

前四周保持现有 Markdown 工作流，不先制作网页、数据库或复杂调度器。

每天：

1. 一个真实句子；
2. 完成独立翻译和批改；
3. 最多晋级3—5个词或短语；
4. 完成到期旧词的无提示复测；
5. 只记录成功、犹豫、失败。

每周：

1. 从本周问题词中选择约20个；
2. 使用新句子进行一次迁移测试；
3. 淘汰已经稳定的项目；
4. 保留反复失败的项目；
5. 检查失败到底来自词、词组、句法还是背景知识。

四周后再决定是否需要自动调度。如果每天的复测量已经可以人工管理，就不开发工具；只有人工队列明显失控时，才考虑增加脚本。

## 最终判断

你现在做的事情有价值，而且比“每天背一页、看着都认识”更接近真实语言能力。

它的价值不在于从242个句子里挖出1,500个词，而在于：

- 用真实句子发现假熟悉；
- 用翻译迫使意义和结构同时落地；
- 用批改保留具体错误机制；
- 用后续真题检验能否再次调用。

下一步不应增加更多输入，而应提高旧输入的再次出现率和提取强度。

可以把整个方案压缩成一句话：

> 真题负责暴露，daily 负责理解，间隔复测负责记住，后续年份负责证明已经学会。

## 研究依据

- Karpicke 与 Roediger 的实验表明，学习后继续进行提取测试，比只继续重读更有利于延迟保持：[The Critical Importance of Retrieval for Learning](https://doi.org/10.1126/science.1152408)。
- 重复提取对长期保持的作用可参见：[Repeated retrieval during learning is the key to long-term retention](https://doi.org/10.1016/j.jml.2006.09.004)。
- 复习间隔应当随希望保持的时间尺度变化，而不是把所有内容挤在同一天重复：[Spacing Effects in Learning](https://doi.org/10.1111/j.1467-9280.2008.02209.x)。
- 词汇在语境中的重复接触会逐步增加不同维度的词汇知识，但单次出现通常不足以形成完整掌握：[The Effects of Repetition on Vocabulary Knowledge](https://academic.oup.com/applij/article/28/1/46/180033)。
