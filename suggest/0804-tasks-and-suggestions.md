## 当前目标

`e2` 以 2016—2025 十套考研英语二真题为核心语料。项目继续以句子分析作为最具体、最稳定的学习动作，但不再把句子隔离成每日一句，也不把真题缩减成五个选择题的答案解析。

每个真题句子都应尽量接通四个方向：

1. 词和词块在本句中的可用含义；
2. 句内关系以及它在段落中的作用；
3. 题目怎样取用、改写或歪曲这段信息；
4. 它能否成为翻译重组、作文表达或后续年份理解的素材。

最终目标不是不断发现错误，而是逐年扩大能够稳定调用的语言资源：2016形成初始存量，2017检验2016并补充增量，随后以同样方式递归推进到2025。

## 当前任务

### 1. 建立完整年度语料

按年份把 PDF 转成可检索的 Markdown，至少完整保存：

- Section I 完形正文与选项；
- Section II Part A 四篇阅读正文与选项；
- Section II Part B 新题型正文与选项；
- Section III 翻译原文；
- Section IV 小作文、大作文题目与图表。

转换不能只追求纯文本正确。原卷中的 **粗体**、*斜体*、<u>下划线</u>、标题层级和图表也属于语料信息，需要在 Markdown 中保留；无法可靠转写的图表使用清晰裁图，并同时给出可搜索的文字说明。

### 2. 重建2016年度底座

2016不是先总结“命题规律”，而是先把整张卷子读通。每一部分完成后，留下能被后续年份调用的具体资源：原句、关系、可迁移表达、题目取用方式和可用于写作的材料。

现有 `analysis/16-text1.md` 暂时保留，供比较旧口径与新口径；待2016完整年度样本成立后，再决定是否归档或重写，不直接删除历史证据。

### 3. 从2017开始做逐年递归

进入新年份前先完成未看解析的作答或理解，再把结果分为四类：

| 分类 | 要回答的问题 |
|---|---|
| 继承并调用 | 前序真题已经提供了什么，这次是否用出来了？ |
| 继承但失效 | 明明见过，为什么没有在当前语境中激活？ |
| 可组合解决 | 单项资源已有，为什么没有把它们组合起来？ |
| 本年新增 | 哪些词义、关系、表达或使用场景确实需要加入？ |

年度结论必须指向具体句子、选项或写作任务，不使用“逻辑更强”“推断变多”“命题更灵活”之类无法执行的概括。

## 建议节奏

第一轮按一个年份约九天推进，之后根据实际新增量动态缩短或延长：

| 日程 | 内容 |
|---|---|
| 第1天 | 完形：完成作答，逐段分析句子和上下文选择 |
| 第2—5天 | 四篇阅读：每天一篇，读通全文，题目用于检验调用 |
| 第6天 | 新题型：处理全文、段落压缩和观点归属 |
| 第7天 | 翻译：独立翻译、逐句校正、记录中文重组经验 |
| 第8天 | 两篇作文：优先调用当年及此前真题语料完成表达 |
| 第9天 | 年度递归：整理继承、失效、组合和新增 |

深度不按“每词平均用力”分配。所有词和句子都在语料范围内，但只有真正影响理解、判断、翻译、写作或后续迁移的内容才进行深入展开。判断是否学到，不看同一道题能否再次选对，而看它能否在后续年份的新语境中被认出、组合和使用。
