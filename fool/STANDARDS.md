# fool 拆解文件标尺

> 本文件是 **fool/** 下愚者拆解文件的生成与质量契约。  
> `auto-review.sh` fool 流程须遵守；与 shell 内 prompt 冲突时，**以本文件为准**。  
> 上游契约：`src/STANDARDS.md`（批改产出的例句为本文件输入）。

---

## 1. fool 的职责

- **输入**：`src/.../dayN.md` 中已批改内容里的英文句子
- **输出**：`fool/.../dayN-fool.md` 中逐句四步拆解
- **目的**：批改里的英二例句，学员单独读仍会懵；fool 把每句拆到**能吸收**的程度，读完等于完成当日**阅读训练量**

fool **不重复批改**，不生成新知识点，只**降维讲解**已有英文句。

---

## 2. 讲解降维标尺（固定，不引用历史文件）

### 2.1 恒定读者画像

与 `src/STANDARDS.md` §2 一致：

| 指标 | 标尺 |
|------|------|
| 首译稳定区间 | **3.5 – 4.5 / 10** |
| 卷面体感 | 英二约 **35 – 45 分档** |
| 能力描述 | 认识不少考纲词形；多义词、介词、嵌套从句、语义极性仍常误读 |

**禁止**：

- 参照仓库内任何历史 fool / probe / src 文件调节深度
- 随当天首译分数升高或降低讲解难度

### 2.2 英文（blockquote 内）

- 与 source **完全一致**
- **不改写、不替换、不简化**英文难度
- fool 的「降维」只发生在**中文讲解**，不发生在英文原句

### 2.3 中文讲解（每条 fool 条目 Step 1–4 合计）

| 规则 | 要求 |
|------|------|
| 总篇幅 | **≤ 12 行**中文 |
| 前后一致 | 第 1 条与最后 1 条**同等密度**；禁止后段缩略、敷衍 |
| 语气 | 像同事面对面讲 |
| 禁用套话 | 不用「综上所述」「简而言之」 |
| 术语 | 语法术语出现时必须**同一行**用白话落地 |

---

## 3. 文件命名与路径

```
fool/<month>/<mmdd>-day<N>-fool.md
```

对应 source：`src/<month>/<mmdd>-day<N>.md`

### 3.1 文件头（保留或新建）

```markdown
# Day N Fool Sessions · YYYY-MM-DD

source: [src/<month>/<mmdd>-day<N>.md](../../src/<month>/<mmdd>-day<N>.md)

---
```

若文件头已存在，**保留**，在其后写入拆解正文。

---

## 4. 收集哪些英文句（顺序固定，不跳过）

按 source 顺序收集 **blockquote / 斜体例句** 中的英文：

| 顺序 | 来源 |
|------|------|
| 1 | `## 原句` |
| 2 | `## Vocab` — 每个词条下 **3** 条 `*斜体*` 例句 |
| 3 | `## Phrases` — 每个短语块下 **3** 条 `*斜体*` 例句 |

**跳过**：

- 中文批注、参考译文、核心意象、例句意图行
- `## 复习区` 全文（旧句重译，已在历史 fool 拆过）
- **造句**（src 已无此字段；若旧文件残留则跳过）

**不跳过** source 中任何符合上述条件的英文句。

---

## 5. 四步拆解（每条 fool 条目）

### Step 1 扫词

- 有分量的实义词：词根**仅当**有助于辨析形近/反义时写 **1 行**，否则只写核心意象
- 每个实义词中文 **≤ 2 行**
- 简单句可极简

### Step 2 扫小品词和搭配

- **只分析** blockquote 内已有英文
- **1 – 2 组**搭配 + 中文感受
- **禁止新增任何英文例句**

**防坑条额外要求**（source「例句意图」含 **防坑** 时）：

必须有一行：

```text
首译典型错读：…；本句纠偏：…
```

### Step 3 扫句式

- **3 – 5 行**
- 用白话：「谁对谁」「挂在谁身上」「逗号后是补充」
- 说清主谓宾与重心
- **禁止**连续堆语法术语而不解释

### Step 4 读句子

两层，分行写：

```markdown
**Step 4 读句子**
直读：…（口语、短句，像转述给朋友）
考场：…（书面译法，1 句）
```

极简单句可省略「考场」行。

---

## 6. 输出格式

按 source 分区组织：`## 原句` / `## Vocab · word` / `## Phrases · phrase`

### 6.1 单条模板

```markdown
### fool-NN [扣原句|迁移|防坑]
> <完整英文，与 source 一致>

**Step 1 扫词**
...

**Step 2 扫小品词和搭配**
...

**Step 3 扫句式**
...

**Step 4 读句子**
直读：…
考场：…

---
```

### 6.2 编号与标签

| 规则 | 说明 |
|------|------|
| 编号 | `fool-01` 起，**两位补零**，全文连续递增 |
| 标题标签 | `[扣原句]`、`[迁移]`、`[防坑]` 与 source 的「例句意图」一致 |
| 映射 | 扣原句 → `[扣原句]`；考纲迁移 → `[迁移]`；防坑 → `[防坑]` |

### 6.3 生成方式

- **一次性**写完整个文件（当前策略）
- 全文条目质量须均匀；后 1/3 不得明显变短或跳过 Step

---

## 7. 与 probe 的关系

| 文件 | 职责 |
|------|------|
| **fool** | AI 生成；可清空后按本标尺**重新生成** |
| **probe** | 学员疑点收件箱；AI **不填写** Q&A |

fool 重生成时**不依赖**旧 fool 内容；只依赖当前 `src` 与**本标尺**。

---

## 8. 质量自检清单（fool 完成后）

- [ ] 文件头 `source:` 链接正确
- [ ] 原句 + 每个 Vocab/Phrase 例句均有对应 fool 条（条数 = 1 + 词数×3 + 短语块数×3）
- [ ] 每条标题含正确 `[扣原句|迁移|防坑]` 标签
- [ ] 每条 Step 1–4 中文合计 ≤ 12 行
- [ ] 防坑条均有「首译典型错读 / 本句纠偏」
- [ ] Step 2 无新增英文句
- [ ] blockquote 英文与 source 一致
- [ ] 后段条目与 fool-01 密度相当

---

## 9. 修订

本标尺随项目演进更新；修改后应同步 `auto-review.sh` 内 fool prompt，并注明修订日期。
