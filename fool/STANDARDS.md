# fool 拆解文件标尺

> 本文件是 **fool/** 下愚者拆解文件的生成与质量契约。  
> `auto-review.sh` fool 流程须遵守；与 shell 内 prompt 冲突时，**以本文件为准**。  
> 流水线版本：**2026-06-22**（完成度见 `scripts/fool.sh`）。  
> 上游契约：`src/STANDARDS.md`（批改产出的例句为本文件输入）。

---

## 1. fool 的职责

- **输入**：`src/.../dayN.md` 中已批改内容里的英文句子
- **输出**：`fool/.../dayN-fool.md` 中逐句四步拆解
- **目的**：批改里的英二例句，学员单独读仍会懵；fool 把每句拆到**能吸收**的程度，读完等于完成当日**阅读训练量**

fool **不重复批改**，不生成新知识点，只**降维讲解**已有英文句。

---

## 2. 讲解降维标尺（固定，不引用历史文件）

### 2.1 恒定读者画像

与 `src/STANDARDS.md` §2 一致：

| 指标 | 标尺 |
|------|------|
| 首译稳定区间 | **3.5 – 4.5 / 10** |
| 卷面体感 | 英二约 **35 – 45 分档** |
| 能力描述 | 认识不少考纲词形；多义词、介词、嵌套从句、语义极性仍常误读 |

**禁止**：

- 参照仓库内任何历史 fool / probe / src 文件调节深度
- 随当天首译分数升高或降低讲解难度

### 2.2 英文（blockquote 内）

- 与 source **完全一致**
- **不改写、不替换、不简化**英文难度
- fool 的「降维」只发生在**中文讲解**，不发生在英文原句

### 2.3 中文讲解篇幅（每条 fool 条目）

**「每条」指什么**：每个 fool 条目——即每个 `### fool-NN` 下、带 `> 英文句` 的那一块；不是整份 fool 文件。

**「Step 1–4 合计 ≤ 12 行」指什么**：这一块里 **Step 1 / 2 / 3 / 4 四段的中文讲解**，按**物理行**加总不超过 12 行。

| 计入行数 | 不计入行数 |
|----------|------------|
| 扫词列表项、搭配感受、句式白话、直读/考场 | `**Step N …**` 标题行 |
| 防坑的「首译典型错读…」一行 | `> …` blockquote 里的英文原句 |
| | `### fool-NN` 标题 |

**为什么要上限**：

1. **一条 ≈ 消化一句** — fool 是阅读训练量，不是百科词条；单条过长读不完、记不住。  
2. **防 Agent 写论文** — 尤其原句+Vocab+Phrases 一次生成 25 条时，无上限易后段塌缩或前段冗长。  
3. **和 Step 分工配合** — Step 1 扫词、2 搭配、3 句式、4 译文各有篇幅；12 行迫使「扫关键、讲清楚、不堆砌」。  
4. **长句靠「只扫关键词」** — 原句实义词多时，Step 1 只扫 2–5 个分量词，不靠把 10 个词全拆满来撑篇幅。

若四步都写满仍超 12 行，优先压缩 Step 3 套话、合并 Step 2 搭配组数，**不得**靠多词挤一行或删掉核心意象来偷懒。

| 规则 | 要求 |
|------|------|
| 总篇幅 | Step 1–4 中文讲解 **≤ 12 行/条**（见上表） |
| 前后一致 | 第 1 条与最后 1 条**同等密度**；禁止后段缩略、敷衍 |
| 语气 | 像同事面对面讲 |
| 禁用套话 | 不用「综上所述」「简而言之」 |
| 术语 | 语法术语出现时必须**同一行**用白话落地 |

## 3. 文件命名与路径

```
fool/<month>/<mmdd>-day<N>-fool.md
```

对应 source：`src/<month>/<mmdd>-day<N>.md`

### 3.1 文件头（保留或新建）

```markdown
# Day N Fool Sessions · YYYY-MM-DD

source: [src/<month>/<mmdd>-day<N>.md](../../src/<month>/<mmdd>-day<N>.md)

---
```

若文件头已存在，**保留**，在其后写入拆解正文。

---

## 4. 收集哪些英文句（顺序固定，不跳过）

按 source 顺序收集 **blockquote / 斜体例句** 中的英文：

| 顺序 | 来源 |
|------|------|
| 1 | `## 原句` |
| 2 | `## Vocab` — 每个词条下 **3** 条 `*斜体*` 例句 |
| 3 | `## Phrases` — 每个短语块下 **3** 条 `*斜体*` 例句 |

**跳过**：

- 中文批注、参考译文、核心意象、例句意图行
- `## 复习区` 全文（旧句重译，已在历史 fool 拆过）
- **造句**（src 已无此字段；若旧文件残留则跳过）

**不跳过** source 中任何符合上述条件的英文句。

---

## 5. 四步拆解（每条 fool 条目）

**四步分工**（前三步**榨干理解**，第四步**只剩翻译**）：

| Step | 层级 | 解决什么 |
|------|------|----------|
| **1 扫词** | 能单独讲清的**词** | 实义词是什么意思（画面） |
| **2 扫词块** | **合读才成立的块** | 不能独立存在：搭配、块内小品词等 |
| **3 扫句式** | **词块没榨干的更大结构** | 从句、`not A but B`（A/B 可嵌从句）、整段重心 |
| **4 读句子** | **翻译** | 把已榨干的理解说出来——**不错即对** |

**Step 2 vs Step 3 怎么切**：

- **词块**：习惯/固定搭配、介词短语、块内小品词（`bothered with`、`concentrated in areas`）——合读才懂，但结构还相对短。
- **归 Step 3**：词块**没解释完**、再长一点的——**从句**（`where…`、`that…`）、**可嵌套的句级结构**（`not A but B` 且 A/B 可能是从句）、整句/大分句的谁对谁与重心。
- 不必等到「整句」才进 Step 3；只要**比词块长、且 Step 2 没狙击完**，就在 Step 3 收尾。

**Step 2 与旧「小品词和搭配」**：小品词不是 Step 1 的单独词，也不是 Step 3 的句式——在**词块**里讲（如 `with` 在 `bothered with` 里）。

**Step 4 的定位**：fool 主要训练**英语读解**，不是打磨中文译文。理解满分不要求纯正书面中文——**逻辑打通、过得分门槛即对**；略像英文语序、未译到最精炼（如 hear 未译成「审」）只要不错，就不是坏翻译。

### Step 1 扫词

**扫谁**：能**单独**讲清含义的实义词（名词、动词、形容词等）。

**不扫谁**：小品词、虚词、搭配块——不能独立讲清，归 **Step 2 词块**（不在 Step 1 单独列 `with`；在 `bothered with the message` 里讲）。

**布局**：每个实义词 **一词一行**（行首 `-` 列表项）；**禁止**多词挤一行。

**每行必有**：**核心意象**（中文画面/力度，不是字典释义罗列）。

**构词（词根拆缀）何时写**：**仅当**有助于辨析形近/反义/多义，或该条为防坑/本次批改错词时，写 **1 行**英文拆缀；否则**不写构词**，只保留核心意象，避免凡词皆拆、篇幅爆炸。

| 情况 | 行内格式 |
|------|----------|
| 需构词 | `- **词**：<构词拆缀>。核心意象：<中文画面>` |
| 不需构词 | `- **词**：核心意象：<中文画面>` |

**构词写法**（需写时，同行内）：`前缀/词根 + 词根/后缀 → 字面直觉`；形近/防坑须加辨析锚点（`注意≠mercy`、`≠ distribute`）。

**篇幅**：每个实义词 **≤ 2 行**；长句/原句只扫 **2–5 个**分量词，为 Step 2–4 留出行数预算（见 §2.3 ≤12 行/条）。

**示范**（生成须达到此样式，**不得**参照仓库内某一天 fool 文件）：

```markdown
**Step 1 扫词**
- **whirlwind**：whirl（旋转）+ wind（风）→ 打着旋儿扫过的风。核心意象：来得猛、转得快；新闻语境比喻行业剧变，不是气象「台风」。
- **harm**：核心意象：造成伤害、损害，比 hurt 更书面。
- **distinctive**：dis-（分开）+ stinct（刺/点，同 distinguish）→ 能区分开。核心意象：有特色；least distinctive = 最同质化。注意≠ distribute（分发）。
```

### Step 2 扫词块

**职责**：blockquote 里**必须合读**、**不能独立存在**的较短片段——各类搭配（固定、习惯）、块内小品词（with / in / to…）。

**不归 Step 2**（归 Step 3）：`not A but B`、嵌套从句、where/that 从句整段——可变得很复杂，词块层讲不透。

**写什么**（**1–2 块**，每块一行列表项）：

```markdown
- **词块**（blockquote 原词，可截取片段）：平行变体 / 变体。中文感受：…
```

- 加粗须来自 blockquote；块在句中可不连续，读时是一块
- **平行变体**用 `/` 分隔，只用本句已有词或同骨架极简省略，**禁止**造新英文例句
- **中文感受**：合读后的语气、方向、主被动——不重复 Step 1，不抢 Step 3

**示范**：

```markdown
**Step 2 扫词块**
- **be provoked to wonder**：rarely provoked to / provoked into wondering。中文感受：被激得去寻思——「被戳到才想」，不是主动好奇。
- **bothered with the message**：bothered with / bothered by。中文感受：被那套论调缠住；with 贴着 bothered。
- **concentrated in areas**：concentrated in / concentrated on。中文感受：损害「落在」领域内，不是挂在表面。
```

**防坑条**（source「例句意图」含 **防坑**）：须另有一行 `首译典型错读：…；本句纠偏：…`（可放在 Step 2 末，计入 §2.3 行数预算）。

### Step 3 扫句式

**职责**：**狙击** Step 2 没榨干的部分——从句、可扩展的句级结构、大分句重心。不必是「整句」才写；只要是**比词块更长、且理解上还悬着**的，在这里讲完。

包括但不限于：

- 定语/名词性从句：`areas **where** newspapers are least distinctive`
- 对比/嵌套：`not A but B`（A、B 均可为从句）
- 分句关系：`but` 前后谁对比、冒号后推论挂在谁身上
- 主谓宾骨架与重心（白话：谁对谁、挂在谁身上）

**3 – 5 行**；用白话，**禁止**连续堆术语而不解释。讲完后，读者应**只剩翻译工作**。

**示范**：

```markdown
**Step 3 扫句式**
where newspapers are least distinctive：修饰 areas，「报纸特色最不突出的那些领域」。
but 连接两半：前半 whirlwind harmed everybody；后半 much of the damage concentrated in…——重心从「谁受伤」转到「伤落在哪」。
```

### Step 4 读句子

**职责**：把 Step 1–3 **已榨干**的理解**说出来**——不是再分析，也不是展示「理想译文」。

**训练目的**：给你**能复制、能练会**的翻译方向，不是永远够不到的范文。读完 fool 你应能：**下一句按同样路径**（先直读气口 → 再考场骨架）自己走一遍，而不是只觉得「人家译得真好我做不到」。

#### 两层各练什么

| 层 | 练什么 | 可复制标准 |
|----|--------|------------|
| **直读** | 气口、谁对谁、先顺下来 | 短句、口语，像转述给朋友；**Step 3 骨架的直接出声版**——你下次可先照这个节奏默念 |
| **考场** | 英二卷面**过得分门槛**的写法 | 1 句书面译；**采分骨架在**（主谓、关键结构、极性别反），不追求辞藻精良 |

#### 质量：不错即对（能学会的三条）

1. **逻辑链可见** — 与 Step 3 一致，不跳步、不反极性；读者能跟上「怎么从英文推到这句中文」。
2. **采分骨架在** — 原句关键结构、易错点（被动、转折、定语从句挂谁）**有体现**即可；不必每个词都译到最美。
3. **不苛求纯正中文** — 略欧化、略生硬，只要**不错**，就是合格训练样本；未译到最巧（如 hear 未译成「审」）≠ 差翻译。

#### 不要写成什么样（反面）

- 央视纪录片 / 母语作家级润色——学员**复制不了**，只会挫败。
- 比 `src` 批改「参考译文」还华丽——fool 考场层**可等于或略简**于参考译文，**不得**明显更考究（那是欣赏对象，不是训练对象）。
- 用 Step 4 补 Step 3 没讲的结构——结构应在 Step 3 榨干，Step 4 **只出声**。

两层，分行写：

```markdown
**Step 4 读句子**
直读：…（短、顺、能默念；复制 Step 3 骨架）
考场：…（1 句，采分骨架在，过得分门槛即可）
```

极简单句可省略「考场」行。Vocab/Phrases 例句：直读必写；考场可 1 句极简或省略（例句以**读懂**为主，不必每条雕中文）。

## 6. 输出格式

按 source 分区组织：`## 原句` / `## Vocab · word` / `## Phrases · phrase`

### 6.1 单条模板

```markdown
### fool-NN [扣原句|迁移|防坑]
> <完整英文，与 source 一致>

**Step 1 扫词**
- **word**：[构词仅当有助辨析时]。核心意象：<中文画面>
（一词一行列表项；核心意象必有；禁止多词挤一行）

**Step 2 扫词块**
- **词块**（blockquote 原词）：平行变体 / …。中文感受：…

**Step 3 扫句式**
（词块未榨干的从句/句级结构/重心；3–5 行白话）

**Step 4 读句子**
直读 / 考场（不错即对，训练读解为主）

---
```

### 6.2 编号与标签

| 规则 | 说明 |
|------|------|
| 编号 | `fool-01` 起，**两位补零**，全文连续递增 |
| 标题标签 | `[扣原句]`、`[迁移]`、`[防坑]` 与 source 的「例句意图」一致 |
| 映射 | 扣原句 → `[扣原句]`；考纲迁移 → `[迁移]`；防坑 → `[防坑]` |

### 6.3 生成方式

- **一次性**写完整个文件（当前策略）
- 全文条目质量须均匀；后 1/3 不得明显变短或跳过 Step

## 7. 与 probe 的关系

| 文件 | 职责 |
|------|------|
| **fool** | AI 生成；可清空后按本标尺**重新生成** |
| **probe** | Agent 写当日内功诊断；学员维护 `internal-skills.md` 状态 |

fool 重生成时**不依赖**旧 fool 内容；只依赖当前 `src` 与**本标尺**。

## 8. 质量自检清单（fool 完成后）

- [ ] 文件头 `source:` 链接正确
- [ ] 原句 + 每个 Vocab/Phrase 例句均有对应 fool 条（条数 = 1 + 词数×3 + 短语块数×3）
- [ ] 每条标题含正确 `[扣原句|迁移|防坑]` 标签
- [ ] Step 1：一词一行；**核心意象必有**；构词仅形近/反义/多义/防坑/错词时写
- [ ] 每条 fool 条目 Step 1–4 中文讲解合计 ≤ 12 行（见 §2.3）
- [ ] 防坑条均有「首译典型错读 / 本句纠偏」
- [ ] Step 2：词块（合读才成立）；不含 not A but B / 从句整段
- [ ] Step 3：词块未榨干的从句/句级结构已狙击；讲完只剩翻译
- [ ] Step 4：直读可默念、考场采分骨架在；可复制练会，非范文级润色
- [ ] blockquote 英文与 source 一致
- [ ] 后段条目与 fool-01 密度相当
