# 英语二新题型：从英文证据走到稳定选择

这里与 `writing/` 同级，管理新题型原题、逐题解答、阅读教学、迁移练习和真实作答记录。沿用写作训练中“先完成历年题，再把经验展开成教学，最后用独立输出验证”的顺序；新题型另补的是英文题干理解、证据定位、人物归属、近似选项排除和改判证据。

已完成 2010—2026 共 17 年、85 题的教师解答与逐题教学，每年另有一组自编迁移练习。2010 是正误判断历史补充，其余年份按各自对应题或小标题题处理。2016—2025 原卷来自仓库，并另整理无答案文本；2010—2015 链接外部原题，不冒充已经归档了完整原卷；2026 明示为考后整理来源。

## 打开以后怎么开始

第一次可以从 [2011](2011.md) 的原题来源打开材料，五题做完再看本课教学；2010 可先作证据强度的基础补充。想直接使用仓库内的无答案文本，就从 [2016 原题](papers/2016.md) 开始。两种入口都不用先背完单词，当前题里改变判断的词与关系必须当场解决。

做题时先留下五个首次答案与总用时，用 [record.md](record.md) 的短格式即可。卡住的地方圈原文，或只说“这一句看不懂”；不要求你另交语法拆分、完整翻译或长篇理由。教学页正常展开，独立作答时先把它移开。

打开逐题教学，先回到引用的英文，再核对作者实际说了什么、题干要求匹配什么、最接近的另一项哪里不成立。每课还把一个容易失控的阅读过程展开，演示如何恢复已读对的部分。最后移开讲解做自编新句。反复换答案时可直接进入 [改判训练](recovery.md)，不强制先做完整专题。

## 哪些状态可以登记

“教师做完”只表示解答和教学已经制作，不代表你做过，也不代表已经教会。当前没有学习者实作记录。原题首做、见答案后的同题复测、自编短句和未熟悉整套限时题分别记录，不能互相冒充。

本轮先排查出词形误认、熟义抢答、未知承重词、长主语边界、被动角色、并列层级、指代、观点归属、否定范围、比较／对照、条件、时间、证据强度、例子夺走主旨、同词干扰以及缺证据改判等风险。这些是备课排查范围，不是对你的错误诊断；收到首次选择或阅读输出后，再确定哪些真的发生，并在当前题里补足。

[教学执行规则](AGENTS.md)约束后续制作；[答案与版本核验](answer-audit.md)供做完后核对，含答案，会提前泄露。`audit.json` 保存机器可读的教师制作状态；学习状态只看真实记录，不按文件数量结算。
