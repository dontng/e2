# 新题型训练的执行约定

本文件只约束 `new-type/` 的制作与训练，承接根目录规则和用户当前指令。

## 先完成题，再形成教学

每一年先完整独立作答，再核对原题证据与参考答案；发现字母差异，先查选项版本，不能抄一个答案串覆盖所有版本。记录题型、原题来源、五题结论、证据和近似项排除；回忆版、缺段与转载错字须明示。选项或材料未齐，不写已核验。

阅读教师不能用自身熟练程度代表学习者。备课时逐处检查：未知词、形近词、熟义误用、动词框架、小词挂靠、长主语边界、指代、否定／条件／时间／范围、人物评价归属、例子与主旨、同词和近义项、证据强度与无证据改判。检查范围不设“每题最多几个问题”的上限，也不要求每题机械凑齐清单。

## 降低门槛，仍然让英文承担判断

起点是词汇不牢、长句可能错接、反复阅读可能产生多个解释的读者。不能要求先补完词汇语法再开始，也不能只给全文中文与正确答案。顺着原文实际信息推进，把改变答案的词和关系当场教清；未知非关键名词可暂按角色占位，承重词随后必须落实。

潜在路径标为“可能”“若这样读”，不能伪造用户心理或声称已发生。收到选择、首译或一句解释后，保留原输出，谨慎定位断点；证据不足就用原句局部或只改变一处的自然英文对比核实。不要求学习者再做显式拆分或填诊断量表。

教学要交代：英文信号在哪里、此处允许什么判断、最近的另一个解释为什么不成立、误读后从哪里恢复。词义用本句可用意思、简单英文或自然例句辅助；形似联想与词根说法不能凭空编造。修一个局部时，保住其余已经由英文确认的部分，不让未知词导致整段重猜。

每年有新语境练习，必要时每题追加，不设固定例句数或篇幅上限。只换人名／同义词不足以证明迁移。讲解和练习核对默认展开；独立做原题时将教学页移开。正文从英文得判断，中文负责解释，不用语法标签和流程口令代替实际理解。

## 选择的稳定性靠证据

保留首次与最终答案，不覆盖首次记录。改判必须说清新增或纠正的英文证据：词义、对象、范围、否定、条件或人物归属。没有新增证据时先复查，不以“越读越不放心”改变答案；也不能把“一律不改第一直觉”当规则。

先教会当前题的断点，再记录真实错误供未来复盘。教师制作完成、用户首做、同题复测、短句迁移、低熟悉完整题限时表现分别登记；未收到作答不得标为已掌握。既往错误再出现时，说明仍需改进教学，不归咎于懒惰或能力。

本阶段默认直接提交并 push main，沿用根目录单目标提交、范围检查和 Codex 署名约定。新增学习结果只能来自真实输出。
