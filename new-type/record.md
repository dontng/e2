# 实作记录：保住第一次选了什么

当前尚无学习者作答。下面只是空白格式，不计完成次数。

一次只需留下五个首次答案、总用时、改过的题和一个卡住处。看懂多少都可以开始；不会的题写 `?`，不要为了凑满先看答案。可以直接把这一段发给 Codex，不要求手写分析表。

```text
年份／来源版本：
是否已经见过本题或答案：
首次 41—45：
最终 41—45：
用时：
改选：题号，原项→新项，新看到或纠正的英文（没有就写没有）
卡住处：圈出的英文／看不懂的题干／一句自己的理解
```

首次答案在第一次明确选定时留下；之后读到相反证据可以改。仅凭不放心也改了，照实保留，不必事后补一个听起来合理的理由。五个选项全记下来，能解决考后只记得犹豫、却不记得最后选什么的问题。

核对以后，Codex 根据真实材料补以下内容，你不用填：正确数、初对终错／初错终对的题、英文证据、当前断点怎样修复、新句结果。初对终对但理由不成立也须修；碰巧猜中不算该关系已会。

同一题看过答案后的再次作答注明“同题复测”，和首次分开。新句迁移只登记当次句子；稳定性最终仍由未熟悉整套题的正确率与用时检验，不因一题成功给整体能力下结论。
