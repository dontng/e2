# 2013：省钱吃好：从例子读出建议，不被共同话题误导

[原题来源](https://www.xhd.cn/news/91001205.html)。本课只摘必要短语，完整材料在来源页；英文迁移句由项目新写。

## 先知道这次要做什么

五段都谈食物和节省开支，主题词本身无法区分答案。要确认每段让读者采取的具体动作：安排、按需购买、保存剩余、与商家熟悉、偶尔犒劳。介绍作者处境的开头只建立背景，不对应第 41 题。

本课五题已经解答，下面按题目位置教怎样从英文得到判断。默认展开便于学习；准备独立做题时，先打开原题，将教学页移开。词不认识先保住可确定的关系，随后仍在本题解决承重词；不把中文大意当作英文已经读懂的证明。

## 41｜菜单和清单共同服务什么

**这处英文要读出来：**

> in advance

先安排菜单，再按准确数量列采购清单；营养均衡是这种安排的好处之一。B 虽然谈饮食平衡，与段落某句有关，却不能覆盖菜单、数量和购买安排。看不懂菜名时先保住提前安排的动作，不能用出现次数决定标题。标题 F 概括做事方法，B 只抓了一个收益。

**作答落点：F。**核对这项的对象、动作与范围；最接近的其他项要在英文中有同样完整的支持，才值得改选。

## 42｜为什么只买一根胡萝卜也有意义

**这处英文要读出来：**

> only need

例子强调需要多少就买多少，不跟着超市预包装重量走。only 限定需要的量，not 后面排除被包装决定的量。这里仍提计划，但计划是实现按需采购的条件；不能因此重新选上一段的标题。先找当前段真正解决的问题：买多了，而不是没有菜单。

**作答落点：E。**核对这项的对象、动作与范围；最接近的其他项要在英文中有同样完整的支持，才值得改选。

## 43｜冰箱、剩菜和水果有什么共同动作

**这处英文要读出来：**

> go off

储存或加工剩余食物，避免其坏掉。go off 在食品语境指变质，不是离开。即使不熟汤料名词，也可由剩余蔬菜做汤、将水果加工两组动作读出防浪费。G 的谚语表示不浪费便不匮乏；不是“不想要食物”。生词占位不能抹掉动作带来的共同结果。

**作答落点：G。**核对这项的对象、动作与范围；最接近的其他项要在英文中有同样完整的支持，才值得改选。

## 44｜为什么建议经常去小店并友善相处

**这处英文要读出来：**

> for free

与商家熟悉以后，更容易获得做汤用的边角食材，甚至免费。段落有很多陌生食材，先按角色占位：肉类边角料、骨头等可利用材料；不需要逐个背完才判断。C 说与店主建立关系，能连接前半的友善和后半的方便；仅说省钱太宽，区分不出这段的办法。

**作答落点：C。**核对这项的对象、动作与范围；最接近的其他项要在英文中有同样完整的支持，才值得改选。

## 45｜节省与偶尔去好餐厅是否矛盾

**这处英文要读出来：**

> treat yourself

这里是犒劳自己，不是治疗自己。虽然不能经常外食，但可以少量积攒后偶尔吃一顿好的。转折把限制与可执行的享受接起来，不能读成作者放弃省钱。D 概括定期给自己一次享受；A 的贫苦生活方向不能覆盖“偶尔奖励”的明确建议。

**作答落点：D。**核对这项的对象、动作与范围；最接近的其他项要在英文中有同样完整的支持，才值得改选。

## 小标题怎么从一个具体例子长出来

先读自编句：

> Buy only what you need today. One carrot is enough for tonight’s soup.

only 紧跟买的范围，第二句用一个胡萝卜说明不要买超过需要的量。标题应能覆盖“按所需量买”，不能把 carrot 当成主旨。若 carrot 不认识，可先记“某种食材”，但 need、only、enough 决定购买量，必须弄清。

与 `Plan next week’s meals before shopping` 比较：这句控制的是购物前做计划，不是单次买多少。两者都可能省钱，却不能因为都属于“节约”就互换标题。回原题时，第 41 段菜单和清单对应计划，第 42 段单买所需数量对应避免多买。再次犹豫就核对控制动作，别把整篇共同目的拿来替每段选答案。

## 移开原题，在新句里重新判断

Read: Make a meal plan before shopping. This can also improve nutrition. In another paragraph, buy just enough vegetables for tonight, even if a larger package looks cheaper.

两段分别选择 Plan first / Buy only the amount needed / Improve nutrition。第一段为什么不选营养？第二段提到购物，为什么也不选计划？

## 复测怎样留下证据

先完成五题，保存首次答案与用时；犹豫处在原文划一条线即可。改选时留下“原选择→最终选择”和新增证据；没有新证据而只是越来越不放心，先检查原证据，不凭这种感觉改选。复盘只修当前不成立的词义或关系，已经由英文确定的部分继续保留。

隔开后回本题，只算同题复测；新句练习通过也只说明这一机制初步可迁移。最终仍看低熟悉完整新题型的独立正确率和用时。当前状态：**教师解答与教学已写；尚未收到学习者首次作答，不登记已掌握。**记录入口：[record.md](record.md)。
