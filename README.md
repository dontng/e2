# e2 · 考研英语二学习项目

以完整英语二真题为主线，保存首次作答、翻译、用时与复盘证据，针对实际失分训练阅读、判断、翻译和写作。项目的目标是把理解转化为能在限时整卷中重复出现的得分；材料整理和讲解制作服务于训练，不代替亲自作答。

2016—2025 年完整真题是核心语料；阅读、新题型与写作模块已扩展整理至 2010—2026 年，各模块注明来源与版本边界。Daily 用于精读和补弱，专项索引用于回看已经发生的错误，娱乐英语用于低压力接触。

## 学习入口

- **完整真题**：[原卷](archive-e2/) · [OCR 文本](e2-ocr/) · [年度分析与复盘](e2-analysis/)。先独立作答，再核对英文证据、选项、用时和输出。
- **阅读理解 Part A**：[reading/](reading/README.md)。包含历年问题发现、局部对照、修复方法与近六年应用审查；从 [个人问题诊断](reading/diagnosis.md) 和 [解决方法](reading/methods.md) 进入。
- **新题型**：[new-type/](new-type/README.md)。按年份进入原题、逐题教学与迁移练习；[作答记录](new-type/record.md) 保存首次选择、改判和用时。
- **写作**：[writing/](writing/README.md)。分别管理小作文与大作文的题目、英文示范、中文内容和评分审查；[中文递进课程](writing/cn/README.md) 从 [10a 小作文](writing/cn/10a.md) 与 [10b 大作文](writing/cn/10b.md) 开始。
- **Daily 精读与翻译**：[src/](src/)。按月份保存原句、首次译文和教学，在当前句里解决词义、结构与关系；较早材料见 [archive-src/](archive-src/)。
- **错词与错接复盘**：[t1/](t1/README.md)。按词形、熟义、句子期待位和中文补空归集真实错误及相似练习；当天问题先在原句中解决，再归档回看。

## 怎样使用

有完整学习窗口时，开始或续接当前年份真题。先留下首次答案、用时和卡住的英文位置，再对照解析：答案依据在哪里，另一项改变了什么，第一次误判从哪里发生。根据真实断点进入相应模块，修复后用新句、新题或间隔复测检查能否独立调用。

时间较短时，可完成当前 Daily 或一项局部训练，保留首次输出即可，不另交长篇拆句报告。写作先练一句切题内容，再练英文表达和限时成文；看懂示范与自己写出分别记录。整卷进度、首次表现和复测结果决定下一步，不按文件数量结算学习成果。

当前阅读、新题型和写作已有教学材料与制作审查，但这些不等于学习者已经掌握。教师方法应用、见过答案的同题复测、陌生材料的独立作答须区分；最终以低熟悉、正式限时的完整英语二试卷验收。

## 2020 年试卷网页

[20.html](20.html) 是完整真题的一种网页入口，支持原文划选、双页翻动和已有原位复盘。它是项目中的具体工具；其他年份真题、Daily 与各训练模块从上面的入口使用。

在 VS Code 中用 Live Server 打开，或在浏览器中预览。左右方向键或页面边缘箭头翻页，F 切换网页全屏，Esc 退出；工具栏在鼠标移到屏幕上沿时出现。原位复盘沿用 X/C/Enter 操作，具体页面与实现说明见 [年度分析目录](e2-analysis/README.md)。尚未提供首次作答的部分，不把原题展示当作个人复盘已经完成。
