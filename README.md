# 2020 英语（二）原卷与原位复盘

[打开完整试卷](20.html)。旧链接 [20-text1.html](20-text1.html) 会进入第 3—4 页并打开复盘。VS Code Live Server 可直接预览；封面单独显示，之后按第 1—2、3—4、……、13—14 页翻动，奇数页在左，偶数页在右。

Chrome 中按 F11 进入或退出全屏；全屏时将鼠标移到屏幕上沿唤出顶栏。鼠标移到左右边缘会显出翻页阴影，点击即可翻页，也可用左右方向键。全屏下双页会按窗口宽度缩放，原文仍可划选。

`20.html` 以改版前的 Text 1 HTML 为基础：第 3—4 页的原文、题目和 13 处折叠解析 DOM 保持原样；原题与复盘、X/C/Enter 的操作保持原样。新增的页放在 `papers/2020/full-paper.js`，用段落、编号空、题干和选项写成可划选的 HTML；`viewer/reader.css` 调整各部分字号、行距、页边距和双页排布，`viewer/reader.js` 只负责翻页与原有复盘操作。第 14 页的图表是从原卷单独裁出的图像，其余题目内容都是文字。

整卷页面不调用 PDF 渲染或 PDF 文字层。仓库内此前产生的 `text-pages.js`、整页 WebP 和构建脚本留作核对历史，不是页面内容或运行依赖。新增部分暂时只有原题，没有对未提供的作答结果编造解析；后续可以单独上传或填写首次作答，再按实际错误补在相应行间。逐页校字、题号和印刷版式时，以 `archive-e2/2020年考研英语二真题.pdf` 中可见的纸面为准，包括原卷里已有的拼写或题号异常。
