# 2020—2026 跨年防错觉方向词、熟词僻义与高频动词框架速查表

> 专门针对“基础偏弱时容易读反方向、按熟义错判、或动词找不到宾语/介词方向”的高危项。考前与平时验证熟练度时，优先过这一张表。

---

## 一、 高危防错觉方向词 / 程度否定短语（一词决定整句正负）

| 英文信号 | 常见错觉 | 考场真实方向与动作 | 真题示例 |
| :--- | :--- | :--- | :--- |
| `barely` / `hardly` / `scarcely` | 当成“稍微有点/几乎是” | **几乎不 / 仅仅（偏否定或极小量）** | `can barely afford`（几乎负担不起） |
| `far from` / `Far from it.` | 当成“离……很远” | **远非、绝非（强否定）** | `far from easy`（绝非易事） |
| `fail to do` | 只当“考试失败” | **未能做到、没有做（= didn't / don't）** | `fail to address`（未能解决） |
| `if any` | 当成“如果有任何” | **即使有也极少（让步削弱）** | `minimal, if any, improvement`（几乎没有改善） |
| `rather than` / `instead of` | 两个都看成“和” | **而不是（否定后者、保留前者）** | `A rather than B`（选 A 不选 B） |
| `not just A, but B` / `more than just` | 只看到 A | **不仅 A 而且重在 B（重心在后）** | `more than just entertainment`（不仅是娱乐） |
| `at best` | 当成“最好、最棒” | **充其量、至多（降调/不乐观）** | `at best a partial fix`（充其量只是部分补救） |
| `all but` | 当成“全都是” | **几乎、差点就（= almost）** | `all but impossible`（几乎不可能） |
| `let alone` / `much less` | 当成“让它独自/少得多” | **更不用说（前否定→后更不可能）** | `can't walk, let alone run`（更别说跑） |
| `not necessarily` / `won't necessarily` | 当成“完全不会” | **未必、不一定（留有余地）** | `won't necessarily mean`（未必意味着） |
| `cannot rule out` | 当成“不能统治” | **不能排除……的可能性** | `cannot rule out confounding variables` |
| `only if` vs `if only` | 混为一谈 | `only if` **只有当……才**；`if only` **要是……就好了** | `succeed only if ...` |
| `not all` / `not every` | 当成“全部都不” | **部分否定：并非所有都……** | `not all employees`（并非所有员工） |
| `too ... to ...` | 当成“非常……所以能……” | **太……以至于不能……（否定结果）** | `too hard to talk`（喘得说不出完整句子） |
| `While ...`（句首） | 当成“当……的时候” | **虽然、尽管（后半句才是作者真立场）** | `While books are ..., a multitude of ...` |
| `given (that)` | 当成“给与” | **考虑到、鉴于（引出已知前提）** | `given the financial pressure`（鉴于财政压力） |

## 二、 2020—2026 跨年高频熟词僻义（熟义 → 考义）

| 单词 | 常见熟义（易错） | 真题考义（必须反射） |
| :--- | :--- | :--- |
| `address` | 地址 / 演讲 | **处理、解决、应对**（`address a problem / issue`） |
| `dismiss` | 解散 / 解雇 | **轻视、不屑一顾、否定**（`dismiss A as B`） |
| `trap` | 陷阱 / 诱捕 | **吸收、截留、困住**（`trap greenhouse gases`） |
| `draw` | 画画 / 拉 | **吸引、招引**（`draw worms / attendees`）；**得出**（`draw a conclusion`） |
| `push` | 推 | **大力推广、推动举措**（`the industry's push`） |
| `check` | 检查 / 支票 | **抑制、阻止、核查**（`keep ... in check`） |
| `house` | 房子 | **容纳、安置、收藏**（`house A with B`） |
| `school` | 学校 | **学派、流派** |
| `coin` | 硬币 | **创造（新词/术语）**（`first coined in 2010`） |
| `secure` | 安全的 | **获得、保住、锁定**（`secure funding / a job`） |
| `employ` | 雇佣 | **采用、运用（方法/策略）** |
| `exercise` | 锻炼 | **行使（权利/权力）**（`exercise power`） |
| `subject` | 科目 / 主题 | **受……影响的 / 实验对象 / 使遭受**（`subject to`） |
| `literature` | 文学 | **（某领域的）学术文献、资料** |
| `suspect` | 怀疑 | **认为……可能成立（倾向肯定）**（`suspect that...`） |
| `prime` | 主要的 | **黄金时期的 / 优质的 / 使做好准备**（`prime muscles for`） |
| `cover` | 覆盖 | **报道 / 行进（距离）/ 足以支付（费用）**（`cover the 500km / cover costs`） |
| `mean` | 意思是 / 吝啬的 | **意味着 / 手段（`means`）** |
| `market` | 市场 | **推销、营销**（`be marketed as`） |
| `fuel` | 燃料 | **助长、加剧、刺激**（`fuel growth / debate`） |

## 三、 高频核心动词搭配框架（一眼定动作方向）

- **归因类**：`attribute A to B`（把 A 归因于 B） / `chalk A up to B`（把 A 归功/归因于 B） / `be rooted in`（根源于）
- **态度否定类**：`dismiss A as B`（把 A 贬低/视作 B） / `overlook A`（忽视 A） / `undermine A`（削弱/损害 A） / `undercut A`（削弱 A）
- **推动促进类**：`foster A`（培养/促进 A） / `facilitate A`（促进/便利 A） / `open the floodgates for A`（为 A 打开闸门） / `drive A to B`（推动 A 走向 B）
- **限制约束类**：`prohibit A from doing`（禁止 A 做） / `ban A from doing`（禁止 A 做） / `hold A accountable to B`（要求 A 对 B 负责）
- **对比取舍类**：`prioritize A over B`（优先考虑 A 而非 B） / `opt for A`（选择 A） / `settle for A`（勉强接受 A）
