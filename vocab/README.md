# 2020—2026 考研英语（二）逐段真题词汇与短语全集

## 标记与用法

- **普通词条**：保障句子顺畅读通的实词与短语，验证能否一眼反应出本段语境义及搭配框架。
- **`★` 考点题眼 / 同义替换词**：直接决定选项对错的题眼词或题干↔原文改写对。
- **`⚠️` 熟词僻义 / 防错觉方向词**：明确写出 `常见熟义/误判 → 本句考义` 对比，专门防熟义抢答、方向读反和否定漏判。
- **同根派生串联**：每篇完形与阅读文末均附同族词串联，辅助跨段/跨年打通词族。
