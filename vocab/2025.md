### 同根派生串联

- **能力与方便**：`compete` → `competent`（有能力的）/ `incompetent`（无能的）；`convenient` → `inconvenient`（不便的）/ `inconvenience`（v./n. 打扰，不便）
- **态度与情感**：`reluctant` → `reluctance`（不情愿）；`comfort` → `comfortable` → `uncomfortable`（不自在的）；`courage` → `encourage` → `encouraging`（令人鼓舞的）
- **行为与评估**：`refuse` → `refusal`（拒绝）；`estimate` → `underestimate`（低估）/ `overestimate`（高估）；`reward` → `rewarding`（有回报的）

#### 同根派生串联

- **流行与预期**：`history` → `historical` → `historically`（历来）；`prevail` → `prevalent` → `prevalence`（普及，盛行）；`expect` → `expectation`（预期）

#### 同根派生串联

- **偏好与反叛**：`prefer` → `preference`（偏好，倾向）；`obey` → `disobey` → `disobedience`（不服从）；`rebel` → `rebellious`（反叛的）
- **能力与适应**：`capable` → `capability`（能力）；`adapt` → `adaptable` → `adaptability`（适应性）
- **坚持与传统**：`insist` → `insistence`（坚持，`insistence on`）；`convention` → `conventional` → `unconventional`（非传统的）
