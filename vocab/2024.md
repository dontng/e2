### 选项高频易混词

| 词汇 / 短语 | 词性 | 辨析与易错提示 |
| :--- | :--- | :--- |
| whereas / unless / until | conj. | `whereas` 表对比“然而”；`unless` 表条件“除非”；`until` 表时间“直到”。 |
| contrast / balance / link / gap | n. | `contrast` 对比；`balance` 平衡；`link` 联系；`gap` 差距/缺口。 |
| misguided / spoiled / disconnected | adj. | `misguided` 受误导的；`spoiled` 被宠坏的；`disconnected` 脱节的、孤立的。 |
| rely on / interfere with / go against | v. phr. | `rely on` 依赖；`interfere with` 干扰、妨碍；`go against` 违背。 |
| cut back (on) / break in / look down (on) | v. phr. | `cut back on` 削减；`break in` 闯入、打断；`look down on` 轻视。 |
| shorten / interrupt | v. | `shorten` 缩短；`interrupt` 打断、中断。 |
| assess / interpret | v. | `assess` 评估；`interpret` 解释、口译。 |
| in turn / on time / by chance | prep. phr. | `in turn` 依次、反过来；`on time` 准时；`by chance` 偶然。 |
| far-sighted / strong-willed / kind-hearted | adj. | `far-sighted` 有远见的；`strong-willed` 意志坚定的；`kind-hearted` 仁慈的。 |
| promote / revise | v. | `promote` 促进、推广；`revise` 修订、复习。 |
| boundary / list / order | n. | `boundary` 边界、界限；`list` 清单；`order` 秩序、订单。 |
| dilemma / injustice / criticism | n. | `dilemma` 困境；`injustice` 不公正；`criticism` 批评。 |
| source / standard / score | n. | `source` 来源；`standard` 标准；`score` 分数。 |
| take over / wipe off / add up | v. phr. | `take over` 接管；`wipe off` 擦掉、清除；`add up` 合计。 |
| ungrateful / responsible / regretful | adj. | `ungrateful` 忘恩负义的；`responsible` 负责的；`regretful` 后悔的。 |

### 同根派生串联

- `energy` n. 精力 → `energise/energize` v. 使精力充沛 → `energised` adj. 充满活力的
- `connect` v. 连接 → `disconnect` v. 断开 → `disconnected` adj. 脱节的、孤立的
- `retire` v. 退休 → `retirement` n. 退休
- `social` adj. 社交的 → `socialise` v. 交际 → `socialising` n. 社交活动
- `irritable` adj. 易怒的 → `irritability` n. 易怒、烦躁
- `avail` v./n. 效用 → `available` adj. 有空的 → `unavailable` adj. 没空的

#### 同根派生串联

- `sustain` v. 维持 → `sustainable` adj. 可持续的 → `sustainability` n. 可持续性
- `produce` v. 生产 → `product` n. 产品 → `productive` adj. 高产的 → `productivity` n. 生产率
- `equal` adj. 平等的 → `equally` adv. 平等地 → `inequality` n. 不平等
- `transform` v. 转变 → `transformative` adj. 变革性的 → `transformation` n. 变革
- `prosper` v. 繁荣 → `prosperous` adj. 繁荣的 → `prosperity` n. 繁荣
- `concentrate` v. 集中 → `concentrated` adj. 集中的 → `concentration` n. 集中
- `dominate` v. 主导 → `dominant` adj. 主导的 → `dominance` n. 主导地位
- `commerce` n. 商业 → `commercial` adj. 商业的 → `commercialization` n. 商业化
- `conceive` v. 构想 → `conception` n. 概念 → `misconception` n. 误解
